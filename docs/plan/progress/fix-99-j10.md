# fix-99-j10: extension JSON member order and tool_execution_update partialResult shape

Base: staging `rev-fix-99-j8` 27ce2c7b7. Pi source: `.upstream/v0.99.1`. Oracle: real upstream 0.99.1 (`extensions/sdk-ts/node_modules/.bin/pi` with `test/parity/testdata/test-faux-provider.ts`).

## Reproduction (real upstream 0.99.1 vs PiG before the change)

Probe extension: a tool returning `details {zeta, alpha:{yy,bb}, mid:[{qq,aa}]}` and a partial update, a `tool_result` handler, `appendEntry`, `sendMessage`, observers for `tool_execution_update/end`, `tool_result`, `context`.

| Surface | upstream 0.99.1 | PiG before |
|---|---|---|
| Node `tool_execution_update` partialResult | `{"content":[{"type":"text","text":"partial"}],"details":{zeta...}}` | `{"content":"partial","details":{alpha...}}` |
| tool `details` (`--mode json`, session file, `tool_execution_end`, `tool_result`, `context`) | written order | sorted keys |
| `tool_result` handler `details` | written order | sorted keys |
| `appendEntry` data, `sendMessage` details (session file, `context`) | written order | sorted keys |
| `context` custom message members | `role, customType, content, display, details, timestamp` | alphabetical |
| `--mode json`/RPC `tool_execution_update` | already `{"content":[]}` then text block (heuristic on "empty text and no details") | same, but codemode's `content: []` + details came out as a text block |

## Out of scope, observed
- PiG session JSONL member order differs from Pi for custom entries (`type, id, parentId, timestamp, customType, data` vs Pi `type, customType, data, id, ...`), and the session file escapes `<>&` as `\u003c`; `--mode json` emits `message_start/end` for `sendMessage` custom messages where Pi does not. Session family.
- Event-level member order of `tool_call` events (`toolCallId` before `toolName`) is PiG-built, not extension-supplied; `tool_result` is fixed here.
- Custom message `content` blocks are written in Pi's order but held as Go maps; a `before_provider_request` replacement payload is still decoded into a map.
- A Go-SDK extension receives event payloads as `map[string]any` (implementation freedom; it can return `json.RawMessage` details, which the conformance row exercises).
