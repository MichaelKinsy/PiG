# Source provenance

This file records the source families distributed in the PiG repository. It complements file-level SPDX metadata and [`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md).

## Repository history

The public repository starts from a reviewed clean source root. Earlier private development history is not part of the public Git history. This file records source lineage without publishing private repository names, paths, identities, or workflow evidence.

## Upstream Pi

PiG translates and adapts source from [Pi](https://github.com/earendil-works/pi).

- Upstream release: `v0.87.1`
- Upstream commit: `f07218c4d4bbc12bef056a7058c3dd49dfe41abe`
- Upstream copyright: Copyright (c) 2025 Mario Zechner
- License: MIT
- Exact pin: [`coding/pigversion/pigversion.go`](../../coding/pigversion/pigversion.go)
- File correspondence: [`PORT_MAP.md`](../../PORT_MAP.md)

The main translated families are `agent/`, `ai/`, `cmd/`, `coding/`,
`internal/codingagent/`, `tui/`, and parity fixtures derived from observed Pi
behavior. The REUSE annotations retain both upstream and PiG copyright
information for translated families.

The `.upstream/current/` directory is a local, ignored mirror. Run `make
upstream-mirror` to obtain the pinned upstream source and verify its tag and
commit. The mirror is not part of the PiG source archive.

## Public documentation website

The website at https://pi-in-go.dev is built and hosted from a separate,
private hosting repository, as pi.dev is for Pi. It renders the user
documentation in `docs/site/docs/` and serves the installer in
`docs/site/public/install.sh` and the knowledge graph JSON-LD in
`docs/knowledge-graph/`, all from this repository. Portions of that
documentation adapt Pi documentation under the upstream MIT license.
PiG-specific pages and revisions carry the project MIT license. `REUSE.toml`
records both copyright families for adapted website documents. The hosting
repository records the provenance of its own site code, data snapshots, and
assets.

## Generated provider data

- `ai/models_generated.go` is generated by `cmd/gen-models` from the pinned Pi provider model data.
- `ai/image_models_generated.go` is generated by `cmd/gen-image-models` from the exact published Pi image-model data for the pinned release.
- `parity/interfaces/` contains generated inventories and reviewed mappings tied to the pinned Pi release.

Regenerate these files with the repository commands. Do not edit generated records by hand.

## Release validation

Before a release, reviewers reconcile this provenance map with:

- the exact source archive;
- language manifests and lock files;
- generated-file inputs;
- embedded assets;
- license scanner results;
- artifact-specific SPDX SBOMs; and
- the final release archives.

See [`docs/supply-chain.md`](../supply-chain.md). A scanner result does not replace this review.
