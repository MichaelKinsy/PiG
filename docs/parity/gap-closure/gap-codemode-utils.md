## Review (rev-gap-codemode-utils, ACCEPT-WITH-FIXES)

The review of `479881539` changes these rows. Fixes are in `485bd00cb`.

- `utils/version-check.ts`: `ComparePackageVersions` now matches node-semver `valid()` in three more cases. It uses JavaScript trim, so a BOM or NBSP is removed and NEL is kept. It rejects a major, minor or patch number above `Number.MAX_SAFE_INTEGER`. It counts the leading `v` toward the 256-character limit. Every case was probed against Pi's bundled semver 7.8.5. A new caller subtest of `TestVersionChecks` checks the `CheckForBinaryUpdate` fallback for a version that is not semver. The `isNewerPackageVersion` assertions of `version-check.test.ts:33-34` are now in the ported case. The proposed `formatVersionCheckError` divergence is **withdrawn**. Go can produce errno names with `x/sys/unix.ErrnoName`. Pi's only caller is the `getSelfUpdatePlan` error text (`package-manager-cli.ts:666-669`), and D39 already replaces that whole message. Record the function under D39 and update the test-mapping rationale, which still names `CompareVersions`.
- `utils/tools-manager.ts`: `archStr` mapped an unknown architecture to itself. Upstream maps every architecture other than arm64 to `x86_64` (`tools-manager.ts:38,41,44,57,60,63`). This is fixed, and `TestArchStr` no longer asserts that riscv64 maps to itself.
- `utils/clipboard-image.ts`: the proposed 0600 divergence is **withdrawn**. Go matches Pi with `os.WriteFile(path, b, 0o666)`, which applies the umask as `writeFileSync` does. The mode is fixed, and `TestSaveClipboardImageToTempFile` checks it.
- `utils/shell.ts`: the signal and crash call sites of `KillTrackedDetachedChildren` had no tests. `TestRPCSignalKillsTheShellOfARunningBashCall` (Linux, child-subreaper helper) and `TestUncaughtCrashKillsTheShellOfARunningBashCall` now fail without the kill. The print-mode call site cannot be observed separately, because the abort on `cancel()` already kills the process group.
- `pig-go.json` has been regenerated, and `interface-go-drift` and `interface-recommendations-drift` are clean.
