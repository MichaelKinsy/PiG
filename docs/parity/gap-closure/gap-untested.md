## Real gaps found and fixed (tests first)

- `ai/azure_config.go` trimmed `AZURE_OPENAI_RESOURCE_NAME` and treated a blank name as absent, then fell back to `model.baseUrl`; Pi (`azure-openai-config.ts:75`) uses the name untrimmed, so a blank name builds an invalid host and fails with `Invalid Azure OpenAI base URL`. The API version also went through the trimming helper (`:102-105`). Red: `TestResolveAzureBaseURLDoesNotTrimTheResourceName`; the API-version half is pinned by `TestResolveAzureConfigDoesNotTrimTheAPIVersion` (added in review, not red-proven because the fix preceded it).
- `ai/overflow.go` used Go's ASCII `\s` in the OpenAI-compatible and Cerebras overflow patterns; JavaScript's `\s` also matches `\v`, no-break and Unicode spaces (`overflow.ts:43,65`). Red: `TestOverflowPatternsEachMatchTheirProviderMessage`.
- Review (`rev-gap-untested`): `ai/overflow.go` used Go's `.` in the Gemini pattern; JavaScript's `.` also stops at `\r`, U+2028 and U+2029 (`overflow.ts:44`). Red: `TestOverflowPatternsEachMatchTheirProviderMessage`.
- Review: `ai/azure_config.go` `normalizeAzureBaseURL` stripped slashes before an ASCII trim; Pi applies `String.prototype.trim` (BOM and Unicode spaces) first (`azure-openai-config.ts:38`). Red: `TestNormalizeAzureBaseURLUsesECMAScriptTrim`.
- Review: `coding/model.go` `matchesProviderHost` used Go's `url.Parse`; Pi's `new URL(baseUrl).hostname` trims, drops tabs and newlines, accepts `https:host` and a backslash path separator, percent-decodes the host, rejects an out-of-range port and keeps a non-special scheme's letter case (`provider-attribution.ts:11-17`). Now uses the WHATWG parser in `internal/nodeurl`. Red: `TestProviderAttributionHostMatchingIsExact`.
- Review: `internal/outputfiles` used `os.TempDir()`; Node's `os.tmpdir()` falls back to `TMP` and `TEMP` on POSIX and prefers `TEMP` on Windows (`output-files.ts:19`). Red: `TestOutputFilesUseNodeTmpdir`.
- Review 2 (`rev-gap-untested-2`): `lazyregexp.NewJSIgnoreCase` emitted every non-ASCII literal as a plain literal of its minimal fold, so `é` did not match `é` and `σ` did not match `σ`; a one-letter class next to a literal (`[s]t`) panicked on first use. It now parses once without folding and closes each literal and class over JavaScript's Canonicalize (toUpperCase unless several units or non-ASCII to ASCII; supplementary characters unfolded), and gives `.` JavaScript's line terminators. Red: `TestNewJSIgnoreCaseFoldsASCIILettersOnly`.
- Review 2: the sibling `utils/retry.ts` provider error patterns and the Codex retry patterns (`openai-codex-responses.ts:125-136`) still used Go's `(?i)` and `.`. Red: `TestProviderRetryPatternsMatchLikeJavaScript`.
