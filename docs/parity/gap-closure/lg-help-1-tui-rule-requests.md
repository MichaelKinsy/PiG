## R2. Optional-parameter overloads (S3/S4 `signature-mismatch`)
Go splits Pi's optional trailing parameter into a base method and a `…With…` variant, or keeps required parameters positional and sets the optional ones through setters. Request: S4 accepts a Go method pair `X()` + `XWith(options)` / `XWithOptions(...)` for `x(options?)`, and a constructor that takes the required parameters while the optional ones are `Set…` calls.
