## Review (rev-gap-ai)

The review kept every verdict except the divergence proposal and fixed these gaps:

- `callback-server.ts`, `openai-chatgpt.ts`: the Go side now parses with the WHATWG URL rules. `internal/nodeurl.ResolveHTTPURL` is `new URL(input, base)` for an http(s) base. `SearchParams` is `URLSearchParams`. `HTTPURL.Pathname` and `HTTPURL.Origin` are Node's `pathname` and `origin`. Requests with `%2e` dot segments or backslash separators reach the route, and a code that contains `;` or a malformed escape is kept. The pasted-URL check compares the WHATWG origin and pathname, so host case, default-port zero padding and dot segments match Pi, and an unparsable port gives Pi's "Paste the full callback URL" message. Tests: `TestResolveHTTPURLMatchesNodeURL`, `TestOAuthCallbackServerMatchesTheWHATWGPathname`, `TestChatGPTManualInputUsesTheWHATWGURL`, `TestChatGPTCallbackServerResponseMatchesSendHtml` (red on the lane head).
- `openai-chatgpt.ts` scope split uses `jsstring.IsSpace`. The duplicate `isJSRegexpSpace` is deleted.
- `faux.ts` `fauxAssistantMessage` takes `timestamp: options.timestamp ?? Date.now()` when the message is built. `TestFauxRegistrationContractUpstream` asserts the creation time and the streamed timestamp.
- `transform-messages.ts`: `transform-messages-copilot-openai-to-anthropic.test.ts` is ported against `ai.TransformMessages` with the production Anthropic ID normalizer (`TestTransformMessagesCopilotOpenAIToAnthropicUpstream`). Its test-mapping evidence named only the Agent (D48) path.
- `scripts/generate-models.ts`: rejected as a numbered divergence. Go can port the deterministic transform over fetched source snapshots. Pi's per-provider patch tables can be ported as data with `// upstream:` citations, and Pi's fixture tests can drive the port. The generator has no user-visible runtime effect, because PiG's catalog is generated from Pi's published data. Keep the row 🟡 with the missing stages listed, or mark it designed-out (n/a) with owner approval. Neither choice needs a `D<N>`.
