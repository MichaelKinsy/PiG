## Ported (real code and tests)
- `pkg:coding-agent/.#resizeImage` (+ `ResizedImage`, `formatDimensionNote` parameter): `imageprocessing.ResizeImage(in, mimeType, options)` returns `ResizedImage{Data, MimeType, ...}`. It honours the declared mimeType for an unresized image (image-resize-core.ts:80). The ledger matched the unrelated unexported `resizeImage(img, w, h)` by name.
- `pkg:coding-agent/.#TruncationOptions` (+ `maxLines`, `maxBytes`): `tools.TruncationOptions{MaxLines, MaxBytes *int}` is now the argument of `TruncateHead` and `TruncateTail` (truncate.ts:78,168). A nil limit takes its default, an explicit 0 is used as given.
- `pkg:tui/.#KeybindingsConfig`: `tui.KeybindingsConfig` is the type of the user overrides taken and returned by the keybindings manager.
- `pkg:tui/.#SelectListTheme::property:selectedPrefix`: test proving upstream's unused `selectedPrefix` is never applied (select-list.ts:193).
- `AgentSession` state members: `Session.SteeringMode`, `FollowUpMode`, `SupportsThinking`, `AutoCompactionEnabled`, `SetAutoCompactionEnabled`, `AutoRetryEnabled`, `IsRetrying`, `RetryAttempt`, `IsBashRunning`, `HasPendingBashMessages` (`coding/session_state.go`). - `AgentSession.exportToHtml`: `Session.ExportToHTML(outputPath)` (`coding/session_state.go`); RPC `export_html` calls it.
- Bug fixed at the source: interactive `message_end` for an aborted turn showed the provider's `errorMessage` ("Request was aborted") in the pending tool rows and ignored retries. Upstream replaces it with "Operation aborted", or "Aborted after N retry attempt(s)" (interactive-mode.ts:3544, :4010). `InteractiveSessionHandle.RetryAttempt` carries the count.
