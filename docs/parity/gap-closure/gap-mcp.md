## Edge differences, fixed

- Title presence: `block.title ?? block.name` and `tool.title ?? tool.annotations?.title` replace only a missing or null title. `mcp.ContentBlock` and `mcp.Tool` now record whether the server sent a title (`HasTitle`), so an explicit empty title stays empty. `TestMCPToolsKeepAnExplicitEmptyTitle` (red before the fix) and `TestToolsAndContentBlocksTrackWhetherTheServerSentATitle`.
- Hiding order: `hideTools` and the re-registration of dropped tools iterate Pi's `Set` in insertion order, the order the server listed its tools. `serverTools` is now an insertion-ordered set (`toolSet` in `extension.go`); a name sort and a map iteration were the previous orders. `TestAgentSessionMCPHidesToolsInTheOrderTheServerListedThem` (red before the fix, both for dropped tools and for a disabled server; the dropped-tool order was random).
