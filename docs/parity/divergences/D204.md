## D204 The Lisp SDK does not yet export TuiAltScreen, Pi's alternate-screen TUI host, where the Node, Go, Rust and Python SDKs do

What: Pi's `pi-tui` exports `TuiAltScreen` (the alternate-screen, viewport-scrolling host that `createInteractiveTui` constructs beside `TuiMainScreen`) and its members. The Node SDK serves it as Pi's own module; the Go, Rust and Python SDKs export it as a proxy for the host's port (docs/extension-api-parity.md, "TuiAltScreen"). The Lisp SDK exports no `TuiAltScreen` and none of its members; a Lisp extension cannot construct one. PiG's own interactive mode paints through its own alternate-screen renderer and is not affected.

Why: the Lisp SDK's pi-tui helper lane has not ported the `Terminal` and `Component` types the export needs; the wire the other SDKs use (`tui.alt`, `tui.alt.cb`) is ready for it.

Pi bug: none claimed.

Scope: the 46 `pi-tui: TuiAltScreen` rows of `test/parity/sdk-exports.toml` (the class and each member) carry `divergence:D204` in the `lisp` cell; their Node, Go, Rust and Python cells are `native:` cells with conformance reach (`TestTuiAltScreenAcrossSDKs`, `TestTuiAltScreenFrameReadsAcrossSDKs`). `docs/extension-sdk-exports.md` is generated from that file. No SDK source changes: the divergence is the absence of the export.

Owner decision: approved by owner Michael Kinsy on 2026-10-26 for the Go, Rust and Python SDKs, which now export `TuiAltScreen`; the Lisp cells carried this id when the Lisp SDK landed on the batch, and the owner confirms that scope when this record is merged.

Call-site markers: none in code; the ledger rows named in Scope are the declaration `make sdk-surface-drift` and `make sdk-exports-release` read.

Evidence: `make sdk-surface-drift` and `make sdk-exports-release` read the rows: a `divergence:D204` cell needs this record, and the release gate does not count the high-use `TuiAltScreen` export (6 scanned packages in `test/parity/extension-import-usage.json`) as a Lisp gap.

Parity allowance: the `divergence:D204` cells are the allowance; no paired Pi corpus constructs `TuiAltScreen` through an SDK, so none changes.

Remove when: the Lisp SDK exports `TuiAltScreen` over the `tui.alt` wire; then the 46 `lisp` cells become `native:` cells with their conformance reach, and this record goes.
