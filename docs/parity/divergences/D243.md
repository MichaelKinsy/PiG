- D243: A bash or PowerShell timeout after the shell already exited reports the shell's exit code. Retired by the pin `1.5.1`, which contains Pi 06aa6563e (fix(coding-agent): report the shell exit code when bash times out after the shell exited, #11813): the pinned Pi's `ShellTimeoutError` carries the shell's exit code and run time, and the bash tool says `The shell exited with code C after S seconds, but background processes it started kept writing output until the timeout.`, as the local shell backend's `*ShellTimeoutError` and the shell tool do, so the two call-site markers are gone. The Go, Rust, Python and Lisp SDKs' `CreateLocalBashOperations` and `CreateLocalPowerShellOperations` still reach the host over `builtinTool.localExec`, whose reply carries only `timeout:<seconds>`, so an extension that wraps them and rethrows prints the plain timeout message. `TestBashTimeoutAfterShellExit11613` holds the behavior.
