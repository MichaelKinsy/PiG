## D177 The calls of a parallel durable tool round start in unspecified order

What: In a parallel tool round (the default `toolExecution`, no call's tool requiring sequential execution) PiG runs each call's tool task as its own goroutine, so the calls start concurrently and the order of their first side effects within one round is unspecified. Pi 1.3.0's generation creates every tool task of the round in one commit and its single event loop runs each `execute` up to its first await in call order, so `harness-tools.test.ts:263` observes `["start a", "start b"]` exactly. Pi does not specify that order; it follows from running on one thread.

Why: Go has no single event loop; ordering the starts would need a gate that holds each call until every earlier call of its round has reached a wait, which couples the harness to the scheduler and to how the runtime parks goroutines. The owner chose to leave the start order unspecified (option b).

Scope: the start order of the tool calls of one parallel round in `durable/harness`. Unchanged: every call of a parallel round starts before any of them ends, the next model request carries the round's tool results in call order, and a sequential round (configured, or required by a tool) runs one call after another in call order.

Owner decision: 2026-10-13, owner approved option b (record the start order as unspecified rather than gate the starts), relayed by DurableLead; number assigned by DurableLead.

Call-site markers: `durable/harness/generation.go` (`createToolTask` in the generation's tool-round commit).

Evidence: `TestToolRound` "runs a round in parallel by default and sequentially when configured or required by a tool" (`durable/harness/harness_tools_test.go`) ports `harness-tools.test.ts:263` with Pi's inputs and checks that the first two events are both starts, in either order, and that the next model request carries the tool results `c1` then `c2`; it fails when the round runs sequentially or the results are reordered.

Remove when: never, unless Pi specifies the start order of the calls of a parallel round.
