## D124 OpenRouter's reported cost is the usage total, ported from pi-mono commit 83ca8020 (pi-mono #9980)

What: Pi 1.4.0 prices every OpenRouter turn from the catalog rates, which can be off by a factor of two or three. pi-mono's unmerged branch `open-router-cost` (commit `83ca8020`, `Fixes #9980`) takes OpenRouter's billed cost instead. PiG ports that commit: for an OpenRouter model (provider `openrouter`, or a base URL that contains `openrouter.ai`) the OpenAI Completions usage chunk and the Anthropic Messages `message_delta` usage replace `usage.cost.total` with the reported `cost` when `is_byok` is `false`, or with `cost` plus the upstream inference cost when `is_byok` is `true` (`cost_details.upstream_inference_cost`, or the prompt and completions parts when that is `null`). Missing, null, negative or non-numeric accounting keeps the catalog total. The `input`, `output`, `cacheRead` and `cacheWrite` components stay catalog estimates. The HTML export (`template.js`) adds `cost.total` and shows the recorded total, falling back to the component sum for sessions written before it existed.

Why: users pay OpenRouter's price, and the footer, session statistics and exports should show it.

Scope: `ai/openrouter_cost.go` (`applyOpenRouterReportedCost`), `parseChunkUsage` in `ai/openai.go`, the `message_delta` case in `ai/anthropic.go`, and `internal/codingagent/export/assets/template.js`, which is Pi 1.4.0's file with the commit's hunks applied (its pinned hash in `TestExportHTMLPinnedAssets` is updated and states both hashes). The vendored Pi dist used by Node extensions is untouched. OpenRouter image models (`openrouter_images.go`) are not changed.

Owner decision: 2026-10-10, owner ruling "fix every confirmed bug now, ported from Pi or not"; port Pi's fix exactly where one exists.
