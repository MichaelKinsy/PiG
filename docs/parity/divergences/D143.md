## D143 A device-attributes reply split across slow reads is not forwarded as input (Pi #10657)

What: when a terminal delivers a DA1 reply in several slow reads, Pi 1.3.0 forwards the leading fragment after its 150 ms fragment timeout and then emits the remaining digits, separators and final `c` as printable key input, so the composer fills with text such as `24;28;32;42c`. PiG ports the issue's reference fix: a buffered private CSI prefix (`ESC[?` and any digits and `;` after it) has no fragment timeout and waits for its final byte. The reassembled reply then takes Pi's path: a DA1 owed to the keyboard protocol query settles negotiation, and any other reply, such as the color query's DA1, is forwarded whole. Input that cannot continue the prefix releases the buffer as input first, as in Pi. A bare `ESC[` is still replayed as input after 150 ms, as Pi's tests require; while a DA reply is owed, PiG then absorbs for one second a continuation that extends it towards a Kitty flags or DA1 reply, so a `?`, digit or `;` typed in that second after a forwarded `ESC[` is consumed too.

Why: A reply to a terminal query is not user input.

Scope: `TerminalInput` negotiation buffering in `tui/terminal_input.go` (`setNegotiationBuffer`, `armOwedReplyTail`, `absorbOwedReplyTail`). A typed `ESC[?` prefix waits for the next key instead of 150 ms.

Owner decision: 2026-10-10, owner ruling that every confirmed Pi bug is fixed now, ported from Pi or not.

Call-site markers: `tui/terminal_input.go` (`setNegotiationBuffer`, `owedReplyTailTimeout`).

Evidence: `TestReassemblesDelayedDA1RepliesForKeyboardAndColorQueries` in `tui/terminal_split_reply_test.go` ports the reference fix's test: both DA1 replies split into the issue's four 8-byte chunks 200 ms apart produce no input until complete. `TestForwardTerminalConsumesAnOwedReplySplitAcrossSlowReads` drives the process terminal's input loop and requires exactly the typed key (and, for a split right after `ESC[`, the replayed `ESC[`). Both fail when the `ESC[?` prefix gets the fragment timeout back; the `ESC[` case fails without the absorber.

Parity allowance: none.

Remove when: Pi keeps a split private CSI reply buffered until its final byte.
