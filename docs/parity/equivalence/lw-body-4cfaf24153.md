# lw-body equivalence (slice S2, base 4cfaf24153)

Every change in this slice keeps the observable output: provider events, their tick order, error texts, and the idle watchdog's decisions. Each change has a reference or an oracle that pins it.

| Change | Why the output is the same | Proof |
|---|---|---|
| Body readiness bridge (`ai/body_readiness.go`, `ai/http_body_observation.go`, Codex reader) | A read is still classified by the same signal: the connection announces a network wait (`bodyReadOwner.pending`) before it blocks. The announcement now suspends the read coroutine instead of sending on a channel, so the caller learns "pending" at the same point. A buffered read still completes inside `begin`; a pending read still completes through `postExternal` with the same job. Only the goroutine that runs the read and delivers it changed. | Tick oracles: `TestAzureResponsesTickOrder`, `TestRPC33AzureTickOrder` (coding), `TestMistralBodyPathTicksMatchPi`, `TestMistralRealBodyTicksMatchPi`, `TestPiMessagesBodyPathTicksMatchPi`, `TestGoogleProviderRoundsMatchNodeRealSockets`, `TestGoogleSDKPipelineMatchesNodeTickOrder`, `TestGoogleProviderConsumerMatchesNodeTickOrder`, `TestAnthropicMicrotaskTrace`, `TestBedrockObservationMatchesPi`, `TestCodexSSEObservationMatchesNodeOracle`, `TestCodexUndiciLatenciesMatchNodeProbe`, `TestCodexSSEOpaqueBodyIsAlwaysPending`, `TestOpaqueFetchBodyObservationIsDeterministic`, plus the `body_readiness_test.go` and `http_body_observation_test.go` unit tests; the bridge tests also pass under `-race`. |
| OpenAI SSE "error" member probe (`ai/openai_stream_decoder.go`) | The map decode now runs only when a top-level member named `error` exists. Names are matched as encoding/json matches a map key (exactly, after unescaping), so the probe answers "would the map have the key". When it does, the original decode runs. | `TestOpenAIStreamParseMatchesMapDecodeRule` keeps the previous `parse` as a reference: 35 records (escaped keys, duplicates, nested and case-variant keys, non-objects, invalid JSON) × 5 event names give the same data, error text and APIError bytes. |
| OpenAI SSE framing (chunk aliasing, line decoder, byte searches) | The same bytes are split at the same places; only who owns the bytes changed. A remainder that aliases the reader's value is copied before the reader is called again. | `TestOpenAILineDecoderMatchesReference` (previous line decoder, 3000 random byte strings × random splits, chunks overwritten after use), `TestOpenAIDoubleNewlineIndexMatchesReference` (20000 inputs), `TestOpenAIStreamDecoderReusedReaderBufferMatchesWholeBody` (reader that reuses its buffer), `TestOpenAIStreamDecoderMatchesSDK` (sdk_sse oracle), `TestOpenAIStreamDecoderFollowsOpenAI719SuspensionPoints`, `TestProvidersRejectMalformedSSEJSON`, `TestProvidersHandleInStreamErrorsLikePinnedSDKs`. |
| SSE idle watchdog (`ai/sse_event_idle.go`) | Same sniff windows (1024 bytes, 64 overlap), same line classification, and the marker search visits the same occurrences: each key is taken left to right without overlap, as the previous `bytes.Index` loop took them (including a key whose closing quote opens the next). | `TestSSEIdleTrackerMatchesReference` (previous tracker, 3000 random streams × random reads, reads overwritten after use) and `TestSSEIdleReasoningMarkerScanMatchesReference` (20000 inputs and limits), plus the `sse_event_idle_test.go` suite. D131 is PiG-only; Pi has no counterpart. |
| Anthropic SSE reader buffer and TextDecoder fast path (`ai/anthropic_stream.go`) | Lines are still cut by `anthropicConsumeLine`, with the D121 hold on a trailing carriage return; only the text before the last decidable line end is converted, once. Well-formed UTF-8 is returned as is, which is what the per-rune loop produced. | `TestWebTextDecoderMatchesReference` (previous decoder, 5000 byte strings incl. BOM, malformed and split sequences), `TestAnthropicSSEReaderMatchesReferenceLines` (previous line draining, 3000 streams × random chunks), `TestAnthropicEventReaderMatchesPi`, `TestAnthropicProviderStreamMatchesPi`, `TestAnthropicStreamSurvivesCRLFSplitAcrossChunks`, the Google tick oracles (shared decoder). |
| Codex SSE framing (`ai/openai_codex_sse_stream.go`) | The same `"\n\n"` frames in the same order, with the EOF separator rule unchanged. | `TestCodexSSEFramesMatchReference` (previous string framing, 4000 bodies × random reads), `TestCodexSSEFramingMatchesPiParseSSE`, `TestCodexTextDecoderStreamsLikeTextDecoder`, `TestCodexResponses*` oracles. |
| Faux pacing (`ai/faux.go`) | Each chunk still awaits its own promise, resolved from a microtask (no rate) or from an external completion after the same delay (rate). Only the timer object and the callbacks are reused. | `TestFaux*`, `TestTestFaux*` (faux observation oracles). |
