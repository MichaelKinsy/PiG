## Responsibilities

Maintainers:

- review and merge changes;
- protect compatibility with upstream Pi;
- maintain project policies; and
- appoint additional maintainers through the process in [`GOVERNANCE.md`](GOVERNANCE.md).

The release authority manages releases and release evidence. The security-response owner coordinates private security reports. [`GOVERNANCE.md`](GOVERNANCE.md) assigns other responsibilities by name through a governance pull request.

A future maintainer change must update this file in the same pull request that records the decision.
