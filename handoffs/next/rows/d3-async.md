# D3 async contracts per upstream file (packages/chord/src/next/store, Go: chord/next/store)

Contracts: awaited, concurrent-joined, detached-owned, cancellable, ui-handoff, microtask-ordering. `ui-handoff` appears in no store file (no UI yields; the one macrotask yield in table-migration.ts is designed out, below). Evidence names are Go tests in chord/next/store/*_test.go (`TestX/sub` = t.Run path). Rows are from the upstream sources that mention async/await/Promise/AsyncIterable (grep): adapter, applier, apply-batch, catalog, engine, export, import, jsonl, outbox, schema, step, store, table-changes, table-handle, table-migration, table-writes. archive.ts, backend.ts and the others have none.

## Missing / designed-out reasons (d3-tests.json)

- missing `claims › an object claims its tables and documents ...`: needs a Chord host (`loaded`, `host.serve`, `self.state`, `self.table`); stays with D5.
- missing `Chord's owners › an int out of range fails only its transaction ...` (refusal.test.ts): needs a host and local object; stays with D5.
- designedOut `row types › types rows with optional opt(...) fields ...` (columns.test.ts): type-level Equal checks only.
- designedOut the two `the chunk yield` cases (table-migration.test.ts): JS timer mechanics (`setImmediate` deleted, `setTimeout` spy, timer starvation); Go preempts, `runtime.Gosched()` yields.
- Ported with a designed-out sub-assertion (kept under ported): export.test.ts the two `getEventListeners` counts (no listener list on a Go context; the later commits prove the queue was given back), table-handle `limit = 1.5` (limit is int64), rows.test.ts BigInt sub-case, applier `meta: 1n` mapped to a `chan int` cell.
