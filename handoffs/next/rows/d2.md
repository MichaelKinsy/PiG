## Open questions for the integrator

- Message representation: a sealed interface with one struct per kind (AGENTS' "discriminated union -> sealed interface"), optional numbers as `Optional[int]`, optional parts/slices as nil. D5/D6 relay code switches on the type; `WithOrigin` copies a message with a new origin.
- `Channel.Handling` is the Go form of the handler's promise; D5's inflate step resolves it from the goroutine that finished the inflate, under the host's serialization.
- Pi's `PartLimits` fields are optional numbers: `*float64` (`new(float64(n))`); `+Inf` is no limit, as in D1's `nextnode.NoLimit`.
- The wire golden (`testdata/link_wire_golden.json`) is regenerated with `node link_wire.mjs <pi tree root>`; it runs Pi's own `binary.ts`, `text.ts`, `values.ts`, `part.ts` with stand-ins for the data layer only.
