# Support

PiG is an open-source project. It does not include a commercial support entitlement or a guaranteed response time.

Use the repository issue tracker for reproducible defects, feature requests, and documentation problems. Search existing issues before opening a new issue. Include the PiG version, operating system, installation method, expected result, actual result, and a minimal reproduction.

Do not include credentials, tokens, private configuration, customer data, or undisclosed vulnerabilities in an issue.

Follow `SECURITY.md` to report a vulnerability privately. Follow `CONTRIBUTING.md` to propose a change.
