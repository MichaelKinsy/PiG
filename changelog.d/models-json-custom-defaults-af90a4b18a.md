### Fixed

- A custom model defined in `models.json` under a built-in provider that omits `api` or `baseUrl` now inherits the provider's composed defaults in `coding.BuildModel`, `--model`, saved default model startup, and RPC `get_state`, matching `ModelRuntime.GetModel` and upstream Pi. Before, a direct stream for a `models.json` custom model that set `api` and omitted `baseUrl` under a built-in provider with several APIs could send the request, with that provider's key, to another vendor's host (for example, `opencode-go` with `anthropic-messages` went to `api.anthropic.com`), while omitting `api` failed with `No API provider registered for api: undefined` and RPC `get_state` reported empty `api` and `baseUrl`. A `models.json` custom model under a provider whose base URL an extension overrides (without declaring extension models) now uses the extension's base URL in `coding.BuildModel` and `--model` too, as the model runtime and Pi do.
