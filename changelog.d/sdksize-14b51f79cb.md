### Changed

- A program that embeds the coding library without loading an extension SDK no longer links the TypeBox type engine, the codemode sandbox (its QuickJS wasm module and wazero) or the tool-search index. `examples/headless` is 0.8 MB smaller than it would be with the SDK export batch. The host answers the `type.engine` call of the Go, Rust and Python SDKs with an engine that the program registers (`coding/extension/pigsdk`, which the `pig` command links, registers it), and the compiled-in extensions that `createCodemodeExtension` and `createToolSearchExtension` name are registered by `coding/extension/builtin`; a program that links neither answers such a reference as a build that strips the extension does: `the compiled-in extension "codemode" is not in this build`.
