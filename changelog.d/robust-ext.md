### Fixed
- Go, Python and Rust extensions now draw an overlay component (`ctx.custom` with `overlay: true`) at the overlay's width, 80 columns by default, as Pi and Node extensions do. They drew it at the full terminal width, so a full-width line was cut off at the overlay's edge.
- `pig -e <directory>` now loads a Node extension whose entry file is `index.mjs` and that has no `package.json`, `index.ts` or `index.js`, as Pi does.
- A Node extension that calls `pi.appendEntry` now sees the new entry in `ctx.sessionManager.getEntries()` in the same handler, as in Pi. RPC mode and interactive mode still report the append (`entry_appended`).
- Pressing a key in a subprocess extension's overlay no longer freezes interactive mode when the key reaches the overlay on the main loop (public PR #197).
- When an extension in a shared Go, Rust or Python process crashes, the error for each stopped extension now says that `/reload` restarts it. Before, the message could only say "packed member connection closed".
- `pig install <dir>` of a local directory with no package manifest and no `extensions/`, `skills/`, `prompts/` or `themes/` directory now loads the directory itself as an extension, as `pi install` does. Previously Pig recorded the Package and loaded nothing from it.
- When a Go, Rust or Python extension that shares a process registers under a different name than the one it was selected by, the error now names both identities, the source, and how to fix the selection, as it already did for an extension in its own process. Before, it said only `packed extension registered as "<name>"`.
- `pig install <dir>` now installs a local Go, Rust or Python extension folder and loads it as an extension, as it already did for a Node folder. Before, it refused the folder with "is an extension, not a package". An npm or Git source whose root is a bare extension is still refused (D57).
- Pressing Escape while an extension tool runs now lets the tool finish: a tool that stops on its abort signal reports its own result or error, as in Pi. A tool that ignores the signal fails with "Operation aborted" after 3 seconds, and the session becomes usable again; Pi waits for such a tool forever (D111). Before, every extension tool call failed at once with "context canceled".
- A Node extension that calls `pi.appendEntry` many times in one handler no longer slows down with the size of the session: each append now costs the same, as in Pi.
