### Fixed

- On Windows, a message a Chord plugin or worker sent just before its Node process exited was lost: the Go side dropped the cut frame without an error. Each frame is now written in a single `socket.write` call, as Pi's transports send it. A frame larger than the pipe's free buffer (64 KiB per direction), or one sent while an earlier write is still pending, can still be lost if the process calls `process.exit()` without waiting for the write's callback.
