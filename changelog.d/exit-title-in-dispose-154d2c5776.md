### Fixed

- The terminal title that a session sets (the session name, or an extension's title) is written where Pi writes it when PiG ends: for a quit by keys (Ctrl+D, Ctrl+C twice, `/quit`) before the "To resume this session" line, and for SIGTERM and SIGHUP before the terminal is restored. PiG wrote it only when the runtime closed, after the exit had restored the terminal and, for a quit, after the resume hint, so a terminal or a recording of the exit saw the title last. A signal that arrives while the quit's last steps are running, or a terminal that has stopped taking output, no longer holds the title write or the exit behind each other. Present in v0.3.0 through v0.7.0 (checked by tag: each runs the title hook only when the runtime closes). <!-- fix: 154d2c5776 -->
