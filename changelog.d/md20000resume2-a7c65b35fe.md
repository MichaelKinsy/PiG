### Changed

- tui: a streamed code block that one construct holds open from its first line to its last (a JSON document is one object or one list; a long block comment) is no longer highlighted again from its start at every frame. The highlighter resumes inside the open constructs, a few lines before the end of the block. The highlighted output is unchanged. Replaying a streamed JSON document of 200 lines frame by frame hands the highlighter 1.21 characters for each character of code instead of 10.30, and takes 85 % less time, 87 % fewer bytes and 87 % fewer allocations. Of the 190 languages the highlighter's samples cover, 47 read less text again when they stream, among them css, xml, scala, kotlin, haskell, erlang, clojure, dockerfile, twig and django; the others read what they read before.
