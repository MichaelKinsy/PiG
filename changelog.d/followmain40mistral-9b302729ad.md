### Changed

- ai: Mistral tool definitions are now sent non-strict by default. A Mistral model receives its tools with `strict: false` and the schema as the tool declares it unless its `compat.supportsStrictMode` is `true`; before, every tool that asked for JSON-schema constrained sampling went out `strict: true` with a converted schema (`additionalProperties: false`, every property required). The new `supportsStrictMode` member (default `false`) of the Mistral compat in `models.json` turns strict tools back on for a model or a Mistral-compatible provider that handles them; a tool that requires strict sampling (`strict: "require"`) now fails before any request, with `Tool "<name>" requires JSON-schema constrained sampling, but strict tools are unsupported.`, on a model without the flag (Pi 2c2a77f9f3ab, #12148). Follows Pi 2c2a77f9f3ab and 2145e3f6099c.

### Fixed
