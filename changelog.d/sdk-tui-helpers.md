### Added

- Extension SDKs (Go `extensions/sdk/tui`, Python `pig_sdk.tui`, Rust `pig_sdk::tui`): Pi's pi-tui helpers `visibleWidth`, `truncateToWidth`, `wrapTextWithAnsi`, `stripTerminalSequences`, `sliceByColumn`/`sliceWithWidth`/`extractSegments`, `getOsc8LinkAtColumn`, `CURSOR_MARKER`, `matchesKey`, `Key`, `parseKey`, `isKeyRelease`, `isKeyRepeat`, `decodeKittyPrintable`, `decodePrintableKey`, `fuzzyMatch`, `fuzzyFilter`, the color helpers (`parseColor`, `rgbColor`, `oklchColor`, `okhslColor`, `colorTo*`, `mixColors`, `foregroundAnsi`, `backgroundAnsi`, `styleText`, `styleTextWithAnsi`), `getCapabilities` and friends, `hyperlink`, `KeybindingsManager`, `TUI_KEYBINDINGS`, `getKeybindings`/`setKeybindings`. Every SDK reproduces vectors generated by running the pinned pi-tui 1.3.0 package's own functions. The SDKs install the host's keybinding table and terminal capabilities as pi-tui's global state, as the Node runtime does, and the Go SDK adds `KeyHint`, `KeyText`, `KeyDisplayText`, `RawKeyHint` and `FormatKeyText`. <!-- fix: 0000000000 -->
