### Fixed

- Concurrent updates, rendering, mouse hit-testing, and transcript node snapshots on `AssistantMessageComponent` no longer race or panic during streaming sessions with subprocess extensions. Before this fix, unsynchronized updates to `childScratch` and thinking-run state raced with concurrent renders and could panic in `Container.renderChildLocked` with a nil child interface (`{0x0, 0x0}`). `AssistantMessageComponent` now serializes component state and layout snapshots while keeping `Text`, `Thinking`, and `IsStreaming` reentrant for render callbacks. <!-- fix: a998e97615 -->
