### Fixed

- An extension that declared one provider name in several `registerProvider` calls while it loaded kept only the last call on the host: `refreshModels` or `oauth` declared first and the other fields declared second lost the first. Pi pushes every call onto an array and applies each in order through the registry, which merges the defined values over the earlier registration (`loader.ts:218-219`, `runner.ts:463-480`, `model-runtime.ts:919-940`), so the host now queues every declaration of a name in order, from Go, Rust, Python, Lisp and Node extensions alike. Tools, commands, shortcuts, flags and renderers still keep the last of a name, as the Maps of Pi's loader do. <!-- fix: 9910d0091 -->
