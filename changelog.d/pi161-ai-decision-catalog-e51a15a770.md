### Added

- `ai` now supports the `pi-decision` classifier API (`ClassifierAPIPiDecision`, `ClassifyPiDecision`, `PiDecisionAPI`, `PiDecisionOptions`, `PiDecisionRequest`, `PiDecisionRequestOptions`, and `PiDecisionResponse`), sending canonical classification requests to `POST <baseUrl>/decision` and returning parsed answers, token usage, and `responseId`.
- `ai` now exposes `ClassifierResult.ResponseID` (JSON `responseId`) across `pi-decision` and System One classifiers, and applies OpenRouter reported billing costs (`Cost.TotalFromProvider`) on System One classifier responses.
- The Radius provider now parses and sanitizes `classifiers` from `/v1/config` (`RadiusGatewayClassifierModel`, `RadiusGatewayConfig.Classifiers`, `GetRadiusAllModelsFromConfig`, `GetRadiusAllModels`), exposes classifier models via `GetAllModels`, and wires `PiDecisionAPI` on `ModelsProvider.Classify`.
- `ai` now supports `xhigh` thinking on Gemini 4 Hydrogen and Neon (`GoogleThinkingLevelXHigh`, `ResolvedGoogleThinkingLevelXHigh`), falls back to the `high` token budget for `xhigh` on budget-based Gemini models, and maps five new Gemini finish reasons (`MISSING_THOUGHT_SIGNATURE`, `MALFORMED_RESPONSE`, `ESCALATION`, `PUP_LIMITED_DISABLED`, `MODEL_ARMOR`) to error stop reasons.
- GitHub Copilot now defines the `gpt-6-luna-decisions` classifier on `openai-decisions` (sharing `OpenAIDecisionsCost` with OpenAI), registers both `openai-decisions` and `typesafe-system-one` under the `/v1` wrapper, and records account decision models in `Credential.AvailableClassifierModelIDs`.

### Fixed

- Gemini 4 models requesting `xhigh` thinking no longer fail thinking-level resolution, and Gemini 2.5 token-budget models now use the `high` budget instead of failing when `xhigh` is mapped. <!-- fix: 28d4c0620a --> <!-- cause: resolveGoogleThinkingLevel and ToGoogleThinkingLevel rejected xhigh and lacked the 3.x Gemini finish reasons -->
- GitHub Copilot OAuth logins and token refreshes now record non-disabled `capabilities.type == "decisions"` models in `AvailableClassifierModelIDs` and filter classifiers per account in `filterGitHubCopilotAllModels` instead of exposing plan-restricted classifiers to every seat. <!-- fix: f209d6c961 --> <!-- cause: GitHub Copilot OAuth only recorded picker-enabled chat models in availableModelIds and never filtered classifiers -->
- Replaced retired Mistral models `devstral-medium-latest` (default Mistral model in `DefaultModelPerProviderOrder`) and `pixtral-12b` in upstream tests with `mistral-medium-latest` and `ministral-14b-latest`. <!-- fix: 1e8d260e95 --> <!-- cause: upstream catalog retired devstral-medium-latest and pixtral-12b -->
- Updated `internal/modelgen` catalog rules to derive thinking-off support from models.dev `canonical_id` entries, enable `requiresNonNullAssistantContent` for affected Cloudflare Workers AI models, drop shut-down OpenAI `gpt-5-chat-latest` and Groq deprecated models plus undocumented `mistral-medium-3.5`, and remove dead `opencode`/`github-copilot` overrides for deleted models. <!-- fix: e51a15a770 --> <!-- cause: catalog builder relied on hardcoded per-provider thinking-off lists and retained removed or undocumented model overrides -->
