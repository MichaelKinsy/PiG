### Added

- `ai` now supports the `pi-decision` classifier API (`ClassifierAPIPiDecision`, `ClassifyPiDecision`, `PiDecisionAPI`, `PiDecisionOptions`, `PiDecisionRequest`, `PiDecisionRequestOptions`, and `PiDecisionResponse`), sending canonical classification requests to `POST <baseUrl>/decision` and returning parsed answers, token usage, and `responseId`.
- `ai` and the Go extension SDK (`extensions/sdk`) now expose `ClassifierResult.ResponseID` (JSON `responseId`) across `pi-decision` and System One classifiers, and `ai` applies OpenRouter reported billing costs (`Cost.TotalFromProvider`) on System One classifier responses.
- The Radius provider now parses and sanitizes `classifiers` from `/v1/config` (`RadiusGatewayClassifierModel`, `RadiusGatewayConfig.Classifiers`, `GetRadiusAllModelsFromConfig`), exposes `GetAllModels` and `Classify` on `RadiusProvider`, and is wired into the coding agent so Radius classifier models are listed and callable through `ModelRuntime.Classify`.
- `ai` now supports `xhigh` thinking on Gemini 4 Hydrogen and Neon (`GoogleThinkingLevelXHigh`, `ResolvedGoogleThinkingLevelXHigh`), falls back to the `high` token budget for `xhigh` on budget-based Gemini models, and maps five new Gemini finish reasons (`MISSING_THOUGHT_SIGNATURE`, `MALFORMED_RESPONSE`, `ESCALATION`, `PUP_LIMITED_DISABLED`, `MODEL_ARMOR`) to error stop reasons.
- GitHub Copilot now defines the `gpt-6-luna-decisions` classifier on `openai-decisions` (sharing `OpenAIDecisionsCost` with OpenAI), registers both `openai-decisions` and `typesafe-system-one` under the `/v1` wrapper, records account decision models in `Credential.AvailableClassifierModelIDs`, and exports `ai.BuiltinFilterAllModels` so coding-agent model filtering honors account classifier lists.
