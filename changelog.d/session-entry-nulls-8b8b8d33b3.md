### Fixed

- A session entry member that an extension sets to `null` is written as `null` and read back as `null`, as in Pi: the `data` of `pi.appendEntry`, the `details` of `pi.sendMessage`, the `data`, `details` and `usage` of a `turn_end` or `agent_before_settle` draft, and the `details` and `usage` of a `session_before_compact` result's compaction and of a `session_before_tree` result's summary. PiG wrote no member, and a reader of the reloaded session got undefined. The cause: the host decoded a member written as `null` and a member left out into the same value, and the entry types leave out a member without a value. A session file that PiG wrote before this change has no member where Pi has `null`; it reads as Pi reads the same file. <!-- fix: 8b8b8d33b3 -->
- An extension's `SessionManager.branchWithSummary(id, summary)` without the `fromHook` argument writes a branch summary entry without a `fromHook` member, as Pi does. PiG wrote `"fromHook":false`. The cause: the entry type could leave the member out only for an entry it had read from a file. <!-- fix: cc387053a6 -->
- A custom message that an extension writes without `display` (`pi.sendMessage({ customType, content })`, a `custom_message` draft without the member) has no `display` member in the session file, as in Pi, and a draft without `content` has no `content` member. PiG wrote `"display":false` and `"content":null`. The cause: `display` was a Go boolean with no "not given" state, and the entry wrote a missing content as `null`. A session file that PiG wrote before this change keeps its `"display":false`. <!-- fix: f71a1836fc -->

### Added

- Extension SDKs: an explicit `null` for an optional member of a session entry. Node `null`; Go `json.RawMessage("null")`, and `SendMessageOptions.Details` for a message's details; Python `pig_sdk.NULL`; Rust `Context::append_entry_opt` and `Context::send_message_with_details` with `Some(Value::Null)`; Lisp `:null`. The empty value of each language (`nil`, `None`, `Value::Null`, `NIL`) leaves the member out, as before.
