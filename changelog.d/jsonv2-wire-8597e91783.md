### Changed

- Faster JSON on the wire (`646e507248`, `f153eff9e8`, `8597e91783`): a Mistral request with 64 messages makes 4 allocations instead of 261 (132 before Go 1.27's engine), marshaling an agent message 16 instead of 34, a command line that carries an image is read in about a ninth of the time, and a host protocol frame in a third to a half. The bytes written match `JSON.stringify`: an agent message or content block that holds a negative zero is written with `0` (it was `-0`) and one that holds an ill-formed UTF-8 byte with the replacement character itself (it was the escape `\ufffd`), from `json.Marshal`, the extension wire and provider request bodies alike, as Pi writes them; nothing else changes. An RPC command line or protocol frame with a lone UTF-16 surrogate (an escape, or its three-byte form), or one that does not decode, is read by the decoder it always was, also when an escaped backslash precedes the text of an escape. One protocol frame difference: a host protocol frame's member names are matched exactly; the old decoder also matched them in another letter case, and the SDKs write the protocol's own spelling.
