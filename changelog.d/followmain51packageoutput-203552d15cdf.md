### Changed

- Follows Pi b513b64d8ac8: at interactive startup, installing a missing git or npm package no longer prints the output of git and npm (`Cloning into ...`, npm summaries and lifecycle script output) before the screen; a successful install shows only `Installing <source>...` and a failed command reports the last 8000 characters of its output. A git package whose remote needs a typed password or ssh passphrase no longer prompts there: git is run with `GIT_TERMINAL_PROMPT=0` (and ssh with `BatchMode=yes` unless `GIT_SSH_COMMAND` is set), so the install fails with a hint to set up a git credential helper or an ssh agent, or to run `pig install <source>` once from the shell. Credential helpers and ssh agents keep working. `pig install`, `pig update` and the print, JSON and RPC modes are unchanged: they keep git and npm output on the terminal.
