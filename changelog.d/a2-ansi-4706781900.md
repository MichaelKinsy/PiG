- Tool output and streamed shell output no longer keep the parameters of private-parameter CSI sequences such as the SGR mouse report `ESC[<35;59;1M`, which left `35;59;1M` in the text. A private prefix (`<`, `=`, `>`) counts only directly after `ESC [` or the 8-bit CSI, so the keypad-mode sequences `ESC =` and `ESC >` still keep the digits that follow them (Pi #11377). <!-- fix: 4706781900 -->
