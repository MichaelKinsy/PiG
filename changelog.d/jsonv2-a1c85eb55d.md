### Changed

- Building PiG from source needs Go 1.27: the root module's `go` directive (`go.mod` and `go.work`) is now 1.27.0 instead of 1.26.0, because its JSON code moves to `encoding/json/v2` and `encoding/json/jsontext`. `go install github.com/MichaelKinsy/PiG/cmd/pig@latest` with a Go older than 1.27 downloads the toolchain `go.mod` names (Go 1.21 or newer), or fails under `GOTOOLCHAIN=local`. The Porter extension and the extension conformance fixtures, which require the root module, move to 1.27.0 with it. The extension SDK (`extensions/sdk`), the other piglet modules, the examples and the Go extensions `pig extension init` generates keep Go 1.26. `internal/jsonopts` holds the one `encoding/json/v2` option set that follows `JSON.parse` and `JSON.stringify`: duplicate names allowed with the last value winning, invalid UTF-8 replaced with U+FFFD, case-sensitive member names, and no HTML or U+2028/U+2029 escaping on output.
