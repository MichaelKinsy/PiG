### Added

- Lisp extensions can now use the `AgentSession` members of Pi that a child session from `ctx-create-agent-session` lacked: the reads (`agent-session-idle-p`, `-streaming-p`, `-compacting-p`, `-current-session-id`, `-current-session-file`, `-current-model`, `-current-thinking-level`, `-current-system-prompt`, `-session-name`, `-steering-mode`, `-get-all-tools`, `-get-context-usage`, `-get-session-stats`, `-get-last-assistant-text` and the rest), the changes (`-set-thinking-level`, `-set-scoped-models`, `-set-active-tools-by-name`, `-set-steering-mode`, `-set-auto-compaction-enabled`, `-set-session-name`, `-clear-queue`, `-export-to-jsonl` and the aborts) and the awaited members, the ones Pi declares `async` (`-wait-for-idle`, `-set-model`, `-cycle-model`, `-reload`, `-compact`, `-navigate-tree`, `-execute-bash`, `-send-user-message`, `-send-custom-message`, `-export-to-html`, `-summarize-for-bug-report`). Each reads or changes the session the host owns; a blocked awaited member never holds a later call, and a cancelled `:ctx` runs Pi's abort for `-compact`, `-navigate-tree` and `-execute-bash`.

### Deprecated

- Lisp: `agent-session-session-id`, `-session-file`, `-model`, `-thinking-level`, `-active-tools` and `-system-prompt` still return what the session held when `ctx-create-agent-session` returned, but they are deprecated. Use `agent-session-current-session-id`, `-current-session-file`, `-current-model`, `-current-thinking-level`, `agent-session-get-active-tool-names` and `agent-session-current-system-prompt`, which ask the host for the current value. The live reads cannot reuse the old names, because a Lisp function has one definition per symbol, so `agent-session-session-id` and the others keep returning the creation snapshot.
