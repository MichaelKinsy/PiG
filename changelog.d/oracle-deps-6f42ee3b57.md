### Changed

- Google providers: the request payload a `before_provider_request` handler (`StreamOptions.OnPayload`) receives for `google-generative-ai` and `google-vertex` now carries `config.automaticContinuation: false`, as Pi's does since f72f799a4 (#12103). It is an option of Pi's Google SDK and is not sent in the request body. The body's member order follows `@google/genai` 2.32.0, the SDK version that commit moves Pi to: on Vertex a `functionResponse` is written as `id`, `name`, `parts`, `response`; on the Gemini API `inlineData` and `fileData` keep the member order of the payload (`mimeType` before `data` for PiG's own image parts); and a replaced payload's `labels`, `continuationToken` and `store` (Gemini API) or `continuationToken` and `generationOutputConfig` (Vertex, sent as `outputConfig`) and a part's `speechMetadata` are sent.
