### Added

- A package manifest may name its changelog with `pi.changelogPath` (default: `CHANGELOG.md` in the package root; a path outside the package root is ignored). Every resource of the package carries the file as the `changelogPath` of its source info, and the new `extensionChangelogVersions` setting records the last changelog version seen per extension package (Pi #8790).

### Fixed

- A package whose `pi` object holds only metadata such as `changelogPath` is loaded by directory auto-discovery instead of loading no resources. <!-- fix: 4706781900 -->
