### Changed

- CI: the light pull-request run's `Linux / test-fast` shard now runs `make ci-test-changed`: the fast packages that `automation/ci/changed-packages.py` selects against the pull request's base branch (the edited packages, every package whose tests import them, and the pigfault tests of the durable driver), without `-race`. A change to `go.mod`, `go.sum`, `go.work` or `go.work.sum`, or to a file no package test reads, runs the whole shard, and the run summary lists the selection and says when and why it fell back. `changelog.d` fragments map to the packages whose Go source names the directory. The full run is unchanged and stays the merge gate.
- `make test-changed` runs a package CI shards (`ai`, `coding`, `internal/codingagent`, the extension host and conformance packages and others) in CI's shards, each in its own `go test` process and timeout, and runs a package the change edits under `-race` in `TEST_CHANGED_RACE_SHARDS` (default 3) times as many shards. A whole-package run outlived `go test`'s 10-minute timeout on a loaded host, and a timeout kill skips `TestMain` cleanup, which then read as scratch-directory leaks.
