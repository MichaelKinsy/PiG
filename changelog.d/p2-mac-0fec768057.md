### Added

- A native macOS app for p2 (apps/p2-mac, Pi's spike): a menu bar item that finds, runs, adopts or stops the local p2 server (`p2 server` from a checkout's build), and windows that show p2's web UI signed in as the local owner (the owner-key challenge of `/owner/local/challenge` and `/owner/local/claim`, the cookie put into the window's own store), with links, downloads, file panels, dialogs and the microphone handled natively. It is Swift (AppKit, WKWebView, macOS 14); the dev supervisor is absent in PiG (D473). The app carries PiG's name (`PiG.app`, menu and window strings) and its own bundle identifier `io.github.michaelkinsy.p2mac`, after the desktop app's `io.github.michaelkinsy.p2desktop` (`apps/p2desktop/mygo.json`), instead of the names of Pi's spike (`Pi.app`, `com.earendil.pi`): the one intentional naming difference. The app icon and the menu bar glyph are the desktop app's PiG pixel pig (`apps/p2desktop/icons/AppIcon.icns`, `cmd/p2-desktop/resources/tray-template.png`), not Pi's logo; Pi's `make-icon.swift` is dropped. <!-- feat: p2-mac -->
