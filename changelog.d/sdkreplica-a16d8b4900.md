### Changed

- The Go, Rust, Python and Lisp extension SDKs now answer the active model object (`ctx.GetModelInfo()`, `get_model_info`, `ctx-get-model-info`: name, context window, limits and prices) and the session id (`GetSessionID`, `session_manager.get_session_id`, `session-get-session-id`) from the host's state snapshot, as the Node runtime always did, instead of asking the host on every read. A read cost 57 µs through the host and costs 75 ns now, and an extension that reads the model twice per LLM call and the session id per prompt sends no host calls for them. The value is as fresh as the Node runtime's: the host pushes the snapshot before every dispatch, after `setModel`, and when the model or the session changes. A replacement session's context still asks the host. `getContextUsage` stays a host call, because Pi computes it live from the branch and a pushed copy goes stale after `waitForIdle`, `compact` and `navigateTree` and for a reader between requests.
