### Fixed

- A data race between the connection read loop of an extension process and a handler whose request had ended without a reply is gone. When the extension process died (or the caller's context ended) after the host sent a `session_start` handler request or a tool call but before the reply was read, the handler goroutine read the dispatch mark that the read loop was still writing. The race detector reported it (`go test -race`, `TestRestartReplacesRegistrationBesideEveryReader`); a user could observe nothing by value, because the mark is read only to order the reply behind notices already sent.
