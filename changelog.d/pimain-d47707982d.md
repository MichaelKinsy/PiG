### Added

- `chord/sqlite` `SqliteExecutor` gains `RunCounted(sql, params...)`, which runs one statement like `Run` and returns the rows it inserted, updated or deleted as SQLite's `changes()` counts them (index writes and trigger changes do not count). The Node driver takes the count from the statement result and the Durable Object driver reads `SELECT changes()` after the statement, because the cursor's rows written also counts index writes. Ports Pi's `SqliteExecutor.runCounted`.

### Changed

- A custom `SqliteExecutor` or `SqliteDatabase` implementation must add `RunCounted`.
