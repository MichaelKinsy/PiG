### Changed

- The address of `examples/ui-view-web/bridge.mjs` works once. It is now `http://127.0.0.1:<port>/#<code>`: the code is in the fragment, which a browser sends in no request and no `Referer`. The page clears it from the address bar at once, posts it in a request body to `/exchange` and keeps the session secret it is answered with in `sessionStorage` (that tab's only; no cookie), sending it as `Authorization: Bearer` on every request, so no address holds a secret after the first load. A code is good for one use and ten minutes; when it is used, or the ten minutes pass, the bridge writes the next one into `open.html` and `address` (mode 0600, in a mode 0700 directory), so open `open.html` again for another tab. A replayed, expired or wrong code is refused, and the page says to open the file again; a tab whose secret the bridge no longer knows says the bridge was restarted. The browser's history may keep the used address, which opens nothing. `--print-token`, or `UI_VIEW_WEB_PRINT_TOKEN=1`, now prints `ui-view-web: http://127.0.0.1:<port>/#<code>`; one run gives one code for one exchange. A script that matched `?token=` matches `/#` instead.
