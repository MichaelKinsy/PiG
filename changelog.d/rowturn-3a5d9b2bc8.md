### Changed

- A chat-completions request is converted without copying its texts or the conversation. A replayed assistant message of one text block is sent as that block's string instead of a copy built for each request, and the messages that lead the request (the system prompt, the first system message's tools) are written into room the conversion leaves instead of every converted message being copied behind them. The request body is the same bytes. On the fake-model benchmark this commit, the next two (session details, hook messages) and nothing else lowered CPU per prompt by 4.0 % in a 20-prompt and a 40-prompt interactive session and user instructions by 4.3 % and 6.9 % (paired runs against the base, 7 and 4 pairs, measured on a build of the three changes together).
