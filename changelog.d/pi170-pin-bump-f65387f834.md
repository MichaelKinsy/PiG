### Added

- Upstream Pi pin moved from `v1.6.1` (`ef4a1cfcca62`) to `v1.7.0` (`fb0fe823539f6d04850f6e34748c01f01f212e1f`), updating model catalogs, schemas, vendored Node runtimes, Chord Protocol v2 runtimes, SDK declarations/vectors/bundles, and parity ledgers.
- `ai` adds the `pi-image` API (`ai.GenerateImages` / `ai.PiImageRequest` / `ai.PiImageResponse`), shared `postJsonRequest` helper, Radius gateway `image` and `decision` catalogs, `Usage.ImageOutput` / `ModelCost.ImageOutput` pricing, and `OpenAICompletionsCompat.SupportsReasoningReplay`.
- `coding/cli` adds `--agent-dir <dir>` (applied before subcommands and carried in session resume commands) and repeats restriction and resource flags in OSC 7577 resume commands (retiring divergence `D662`).
- `chord` adds Protocol v2 (`ProtocolVersion = 2`) with `grantable` state, `admit`/`allow`/`deny`, `Bound.Granted`, `Self.Follow`, `TuiScope.Live`, `Plugins.Apply`/`ApplyWith`, shared first-making of plugin sets, commit-indexed shared live reads, and `FileSystemSyncRemote`.
- `extensions/sdk/upgrade` adds `RuleInstallTelemetryRemoved` diagnosing removed `SettingsManager` install telemetry methods.

### Changed

- `ai.CalculateCost` and `CalculateCost` across all extension SDKs (Go, Python, Rust, Common Lisp) price image output tokens at `ModelCost.ImageOutput` (falling back to full output when a provider omits the split) and compute output cost as `(output * (usage.output - imageTokens) + imageRate * imageTokens) / 1000000`.
- `ai` replays GitHub Copilot `reasoning_opaque` in `openai-completions`, preserves GitHub Copilot prompt caching across effort/tool changes (`supportsMidConvoToolChanges`), stops sending earlier reasoning to Bedrock Kimi K3 models, sends flat `reasoning_effort` for Bedrock Kimi K3 / GLM 5.3, and updates default models (`ant-ling` `Ling-3.1-flash`, `cloudflare-workers-ai` / `cloudflare-ai-gateway` `glm-5.3`).
- `coding` and `coding/cli` report `models.json` load failures as runtime `Warning: models.json error:` diagnostics in every mode, always send PiG provider attribution headers, exclude `!!` bash output from compaction context token estimates, apply autocomplete on follow-up submit, use configured key hints in TUI components, and append Kitty images differentially without full redraws.
- `env/daemon` kills every process in a terminal or command session across process groups on shell exit or close (using `pidfd` on Linux and `getsid` verification on macOS/Unix), while processes that leave the session via `setsid` remain untouched.

### Removed

- Removed install telemetry reporting (`/api/report-install`), the `enableInstallTelemetry` setting, `PI_TELEMETRY` / `PIG_TELEMETRY` / `PIG_INSTALL_TELEMETRY_URL`, and `SettingsManager.GetEnableInstallTelemetry` / `SettingsManager.SetEnableInstallTelemetry` across Go, Python, Rust, and Common Lisp extension SDKs (Pi v1.7.0 `484da3a86`).
- Removed Chord v1 `variants` / `useVariant` APIs in favor of Chord Protocol v2 `grantable` / `admit` / `useLive`.
