### Added
- A fused Go Piglet member can decide which failed model requests PiG retries and how long it waits (`clihook.RetryPolicy.Decide`), with the status, the response headers and whether the stream had started; the same decision covers the summarization request of a compaction. `Silent` removes PiG's own interactive retry status line and its final "Retry failed after ..." line, and Escape still cancels the retry delay. `HTTPIdleTimeoutMs` sets the default HTTP idle time-out when `settings.json` names none. A `message_end` replacement from an extension keeps the failure response of the message it replaces. Nothing changes without a member that uses it: a failed request builds no failure response and allocates what it did before, and the response is never written to a session file, to RPC or to JSON mode (D654).
