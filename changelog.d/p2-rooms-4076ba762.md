### Added

- p2 follows Pi main for custom views' rooms: a custom view's page can share a room on the server with every other browser showing the view (people the session is shared with included): presence and a leader, ordered messages (keyed ones fold for slow peers), log rooms that save snapshots into the view's state, and text rooms that merge concurrent typing on the server; the page's own link to its room carries a short-lived token and a view principal that reaches nothing else, and is ended with its view, its opening or its viewer. The agent can offer-and-call methods a page offers (`view_methods`, `view_call`, code mode only). One memory budget bounds all rooms (settings.json `viewRoomsMemory`, MiB, default 64).
