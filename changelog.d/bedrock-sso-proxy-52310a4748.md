### Fixed

- Bedrock: with `HTTPS_PROXY` or `HTTP_PROXY` set, an AWS SSO / IAM Identity Center profile could not fetch role credentials (`GetRoleCredentials`) or refresh an `sso_session` token (`CreateToken`), and an `aws login` / `login_session` profile could not refresh its Signin token (`CreateOAuth2Token`), because those calls bypassed the proxy and went direct. Bedrock now routes SSO, SSO OIDC, and `login_session` Signin credential calls through the same proxy resolved for the Bedrock endpoint, alongside the Bedrock runtime and STS (`AssumeRole` / `AssumeRoleWithWebIdentity`) calls, while IMDS, container credentials, `credential_process`, bearer tokens, `AWS_BEDROCK_SKIP_AUTH`, and static environment keys keep their existing direct behavior.
