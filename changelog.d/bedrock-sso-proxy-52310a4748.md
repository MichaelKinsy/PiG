### Fixed

- Bedrock: with `HTTPS_PROXY` or `HTTP_PROXY` set, an AWS SSO / IAM Identity Center profile could not fetch role credentials (`GetRoleCredentials`) or refresh an `sso_session` token (`CreateToken`), because both calls bypassed the proxy and went direct. Bedrock now routes SSO and SSO OIDC credential calls through the same proxy resolved for the Bedrock endpoint, alongside the Bedrock runtime and STS (`AssumeRole` / `AssumeRoleWithWebIdentity`) calls, while IMDS, container credentials, `credential_process`, bearer tokens, `AWS_BEDROCK_SKIP_AUTH`, and static environment keys keep their existing direct behavior.
