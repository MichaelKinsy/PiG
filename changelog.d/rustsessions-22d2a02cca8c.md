### Added

- Rust extensions can now use the `AgentSession` members of Pi that a child session from `ctx.create_agent_session` lacked: the reads (`is_idle`, `is_streaming`, `is_compacting`, `session_id`, `session_file`, `session_name`, `model`, `thinking_level`, `system_prompt`, `steering_mode`, `get_all_tools`, `get_context_usage`, `get_session_stats`, `get_last_assistant_text` and the rest), the changes (`set_thinking_level`, `set_scoped_models`, `set_active_tools_by_name`, `set_steering_mode`, `set_auto_compaction_enabled`, `set_session_name`, `clear_queue`, `export_to_jsonl` and the aborts) and the awaited members, the ones Pi declares `async` (`wait_for_idle`, `set_model`, `cycle_model`, `reload`, `compact`, `navigate_tree`, `execute_bash`, `send_user_message`, `send_custom_message`, `summarize_for_bug_report`, `export_to_html`). Each one runs on the host's session over `childSession.op` and `childSession.opAsync`, so it returns what the session holds now. A member Pi awaits blocks until it settles; call an abort from another thread to cancel it.

### Upgrading

- Rust: the `session_id`, `session_file`, `model`, `thinking_level`, `system_prompt` and `active_tools` fields of `AgentSession`, which held the values at creation, are now methods that read the session's current values and return `io::Result`: write `session.session_id()?` where you wrote `session.session_id`, and `session.get_active_tool_names()?` for `active_tools`.
