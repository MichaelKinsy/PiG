### Changed

- An interactive `pig` session holds about 3 MB less memory once it has started. The first frame and the start-up loads allocate several times what they keep, and Go's background scavenger returns the rest slowly; the task that registers the remaining syntax grammars now hands that free heap back to the operating system once, after it has queued the repaint, so it never runs on the input loop. On linux/amd64 with a fresh home, the median resident (and proportional) set at the first frame, one second later and after ten idle seconds is 46.9 MB (46.4-47.1, N=16) against 50.1 MB (50.0-50.5, N=16) before; the median time to the first full frame is 24.9 ms (21.4-33.1, N=60) against 24.9 ms (21.2-33.5, N=60), and the median time from a keystroke to its echoed frame is 0.93 ms (0.04-6.21, N=1,580) against 0.91 ms (0.04-4.49, N=1,580). <!-- fix: bdff0a71 -->
