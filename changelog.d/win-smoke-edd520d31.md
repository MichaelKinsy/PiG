### Fixed

- `pig piglet build` times the artifact's `--version` check from the moment its process exists, not from the moment the operating system was asked to start it, so a slow first start of the freshly signed executable is no longer charged to the 60 s budget. On Windows a healthy Binary failed with "basic artifact verification timed out after 1m0s"; the leading hypothesis is that Windows scans the new executable while starting it, which has not been measured. A hung artifact still fails after 60 s, and the error now shows how long the start took and what the process printed; a canceled build reports its cancellation. A start the operating system never returns from is not bounded. <!-- fix: edd520d31 -->
