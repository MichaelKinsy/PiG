### Changed

- Durable's and Chord's watches, observers and reports share one vocabulary, as in Pi (`5f312dac`). A watch listener gets a tagged `WatchCall`: `WatchCallValue` (the value, its ops, `Retired`) or `WatchCallFailed` (the error of a failure the source recovers from; the watch stays open and the next value arrives as `[["r", value]]`). `WatchEnd`, `SessionEnd` and `ReportFrom` carry their tag in `Kind`, an aborted context ends a watch `aborted` (was `cancelled`), and `Observer.End` takes a `WatchEnd`. `HarnessOptions.OnReport` gets one `Report` (`Kind`, `Error`, and the fields of its `ReportInfo`); the report about a failed Session is `storage_failed` (was `session_failed`), and a `task_outdated` report uses the scheduler's reasons (`missing_task`, `task_too_old`, `migration_failed`; `incompatible_task` is gone). `Session.SubscribeCommits` is `ObserveCommits` and takes a `CommitObserver` that is told when the Session ends; `FileChange` has a `FileChangeFailed` variant (was `FileChangeError`) and a `FileWatcher` is stopped with `Stop` (was `Close`). A committed document retirement is a `DocumentRetireChange`, and `TaskInspection` calls a task the next scheduling pass reserves `pending` (was `ready`). Go callers of these names must change; the old names are removed.

### Upgrading

- The stored format of `pi.live` changes: its version is now 2, and a compaction's trigger is stored as `trigger` (was `reason`) in `compactions` and `compactionFailure`. A conversation stored by an earlier version reads through a migration that renames the key, so existing stores open unchanged; a store written by this version cannot be read by a build that still expects `pi.live` version 1 (the previous Pi and PiG releases). The Cloudflare host facade and the Durable core's wire follow: report info is tagged `kind`, and a document commit change is `{type:"document", kind:"change"|"retire"}`.
