### Added

- `make sdk-surface-drift` now guards the package half of Pi's extension surface. `test/parity/sdk-exports.toml` records, for every runtime export and public class member of `pi-coding-agent`, `pi-tui`, `pi-ai`, `pi-ai/compat` and `pi-agent-core`, what each of the Go, Rust and Python SDKs offers: a native symbol, a component-kit view, a context call, an identity (a type), a numbered divergence, or a `gap:<lane>` whose lane names an owner and the row that closes it. There is no free-text n/a, deferred or pending. A Pi export that appears without a row, a gap whose lane is gone or past its train limit, and a realized cell that no conformance fixture or Pi-generated vector test reaches all fail the check. `make sdk-exports-release` (run by `interface-mapping-strict`, so by `foundation-check`) also fails a gap on an export that five or more of the scanned npm Pi packages import (`test/parity/extension-import-usage.json`, refreshed by `automation/gen/sdk-import-usage.py`). The readable form is `docs/extension-sdk-exports.md`. <!-- fix: 82f59b27 -->
