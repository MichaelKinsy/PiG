### Added

- The built-in documentation has a page for extension views, `ui-views` (`pig docs show ui-views`). It describes how an extension mounts one view that the terminal and a web page draw (D614): the mount calls, the node kinds, intents, alternatives chosen by a client's claims, accessibility and focus records, drawings, slots, errors, the calls of each SDK and what each client draws. Its two complete Node extensions run in a test.
