### Security

- Updated the pinned Go toolchain from 1.27.3 to 1.27.4, which fixes GO-2026-6859 (an HTTP/1 server crash from a data race on the response header map when `net/http.MaxBytesReader` or `MaxBytesHandler` limits a request body) and GO-2026-6848 through GO-2026-6858 (cgo compiler and linker flag injection). `govulncheck -show traces` at Go 1.27.3 reported only GO-2026-6859 as reached, through 64 example traces to `net/http` symbols. The trace nearest the flaw is `net/http.maxBytesReader.Read`, reached from `googleSSEReader.Read` in `ai/google.go` through `io.LimitedReader.Read`. PiG code does not call `MaxBytesReader` or `MaxBytesHandler` directly. `govulncheck` did not report GO-2026-6848 through GO-2026-6858. It failed on every build with the previous toolchain because of GO-2026-6859.
