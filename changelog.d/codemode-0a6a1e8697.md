### Added

- A Go program that embeds Code Mode in a macOS app signed with the Hardened Runtime can run it without a code-signing entitlement: `Interpreter: true` on `codemode.SandboxOptions` (and `InlineSandboxOptions`), `codemode.ServeOptions`, or the built-in extension's `Options` runs the QuickJS sandbox on wazero's interpreter instead of its compiler. The compiler stays the default. Without the option, such an app is killed (SIGKILL) the first time a script runs unless it carries `com.apple.security.cs.allow-unsigned-executable-memory`; `com.apple.security.cs.allow-jit` alone does not help. The interpreter was about 50 times slower on two measured scripts (26 ms against 1.2 s, 152 ms against 8.4 s), so the entitlement is the better fix where the app can carry it. The `pig` command is not affected (D263, issue #410).
