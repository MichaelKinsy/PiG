### Changed

- A component's `render` in the Go, Rust and Python `TuiAltScreen` may call its screen and change it: the host runs each such call at once on the goroutine that draws the frame, while it holds the frame lock, so a change applies immediately and a later read in the same render sees it, as in Pi. A child a render adds is rendered by the frame in progress. `render`, `renderNow`, `start`, `stop`, `copyActiveSelectionToClipboard` and `queryTerminalColors` called from inside a render return the error `tui.alt: <op> cannot run while a component renders` where Pi recurses (D208). `children` is a copy of Pi's live array: read it again after `addChild`, `removeChild` or `clear` (D207). The Go SDK takes pointer components only and rejects any other value with an error at the call that receives it, because Pi compares components by reference. <!-- feat: 1d917fc889 -->
