### Fixed

- On Windows, saving `auth.json`, the settings, trust, keybindings and MCP files, or any other file pig writes through a temporary file, now leaves the whole security descriptor and user-settable file attributes (`HIDDEN`, `SYSTEM`, `NOT_CONTENT_INDEXED`; `ARCHIVE` stays set on rewritten content) of the file as they were, as Pi's in-place write does. The access (the DACL entries with their flags, and the protected flag) is carried onto the temporary file before anything is written to it and read back, then verified again before moving the temporary file over the target in one `MoveFileExW` call; a file system that cannot take the access gets the in-place write, as before (divergence D651). <!-- fix: 1f4ce560a8c2, 950803e7b7da --> <!-- cause: the helper previously relied on ReplaceFileW merging and copied only the DACL with its protected flag, and no test compared the whole descriptor before and after a write on Windows -->
