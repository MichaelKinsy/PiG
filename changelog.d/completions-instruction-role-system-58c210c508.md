### Changed

- Reasoning models on `openai-completions` now send system messages (the initial system prompt and mid-conversation system messages) with the `system` role instead of `developer` for Groq, OpenRouter (`openai/*` and `anthropic/*`), Xiaomi, custom `models.json` providers, local servers, and other hosts that omit `compat.supportsDeveloperRole`. Provider `openai` (on any base URL), endpoints whose base URL includes `api.openai.com`, and bare `OpenAIConfig` defaulting to `openai` / `api.openai.com` keep `developer` by default.
