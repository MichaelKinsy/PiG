### Fixed

- A full disk or a killed process while pig saved `keybindings.json`, `mcp.json` or the settings file during the legacy API-key migration could leave the file empty or cut short and lose your keybindings, your MCP servers or your settings. These files are now replaced as a whole through a temporary file in the same directory, so a failed write leaves the old file untouched. Where one of them cannot be replaced atomically, for example a single file mounted into a container or a file in a directory pig cannot write into, pig writes it in place as before. <!-- fix: 8d4e7f2452 --> <!-- cause: these files were written with os.WriteFile, which truncates the file before it writes, so a write that failed after it began left an empty or cut-short file. -->
