### Fixed

- The regular-mode renderer no longer writes OSC 133 prompt markers to the terminal. Terminals that show program status read them as a new shell prompt and dropped the working indicator during runs. Fullscreen mode still uses them for prompt navigation. <!-- fix: c60a7b14aa -->
- Bare URLs in Markdown now stop at CJK punctuation such as `，` and `。`, so Chinese, Japanese and Korean text after a URL is no longer part of the link. Explicit `[text](url)` links and `<url>` autolinks keep these characters. <!-- fix: c60a7b14aa -->
