### Fixed

- A theme file in the agent directory's `themes/` now loads when it is selected by its file name although the name inside the file differs (`themes/proto.json` with `"name": "other"`, selected as `"theme": "proto"`, `--use-theme proto` or an extension's `ctx.ui.setTheme("proto")`). PiG refused it with `Theme not found: proto` and fell back to the system theme, where Pi loads it. <!-- fix: b637cd4647260ed2b9feef32a13cf16d7c54c8f0 -->
- When the selected theme's file exists but fails to load, the `Failed to load theme "<name>":` line and the result of an extension's `ctx.ui.setTheme` now give the reason, as Pi does: for example `Variable reference not found: nosuchvar`, the JSON syntax error, the validator's list of missing color tokens, or the file-system error for a file that cannot be read. PiG said `Theme not found: <name>` for every such file since 0.4.0; only a name without a file is still "Theme not found". <!-- fix: b637cd4647260ed2b9feef32a13cf16d7c54c8f0 -->
