### Fixed

- A Node extension whose factory failed, because it has no default export or throws while initializing, could be reported as `connect:process_exited ... exit status 1` instead of Pi's "Extension does not export a valid factory function: <path>" or "Failed to load extension: <message>". The extension's runtime reports that error over its socket and exits; on a loaded machine the host looked after the exit and chose between the connection and the exit by whichever it noticed first, which failed about 1 run in 20 of the upstream extension-discovery tests. The host now accepts the connection the extension made before it exited, in both a packed cell and an isolated process, and reports `process_exited` only for a process that never connected.
