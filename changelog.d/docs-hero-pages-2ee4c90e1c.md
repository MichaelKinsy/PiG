### Added

- The built-in documentation has two new pages. `event-bus` (`pig docs show event-bus`) shows how one extension calls another through `pi.events`, across languages: a Go extension asks and a Node or Python extension answers, with the calls of the Node, Go, Python, Rust and Lisp SDKs and the rules of delivery (payload by value, order, no listener, a failing listener, reload; D83). `go-hot-reload` (`pig docs show go-hot-reload`) gives the steps to edit a Go extension and run the change with `/reload` in the running session, what the screen shows, what a reload keeps and what a failed build shows (D70). The complete extensions of both pages run in the real binary under `TestDocsEventBusPage` and `TestDocsGoHotReloadPage`. `extensions.md` now states what `/reload` keeps: an extension whose source did not change keeps its process, and an edited Go extension runs in a new process.
