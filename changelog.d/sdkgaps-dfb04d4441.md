### Added

- The Go, Rust and Python SDKs export every remaining member of pi-ai's `Type` (TypeBox 1.3.27): `Pick`, `Omit`, `Partial`, `Required`, `KeyOf`, `Index`, `Mapped`, `Conditional`, `Extends`, `ExtendsResult`, `Evaluate`, `Instantiate`, `Exclude`, `Extract`, `NonNullable`, `Capitalize`, `Lowercase`, `Uncapitalize`, `Uppercase`, `Parameters`, `ReturnType`, `ConstructorParameters`, `InstanceType`, `Function`, `Constructor`, `Tuple`, `TemplateLiteral`, `Cyclic`, `Module`, `Interface`, `Call`, `Generic`, `Script` and the rest, with their `Is...` guards. Pig ports TypeBox's type engine once, in the host, and every SDK asks it through a blocking request while a schema is built, so each member returns exactly what Pi's `Type` returns, member order and hidden markers included, and is checked against Pi's own answers for hundreds of cases. A `Record` whose key is an enum, an intersection or a template literal now works too. A schema can hold a bigint (`Type.Script("1n")`) as Pi's value does and fails only when it is written as JSON, with Pi's "Do not know how to serialize a BigInt"; the Python SDK raises "Invalid Arguments" for `Infer`, `Parameter`, `Script` and `Refine` called with another argument count, as Pi does.
