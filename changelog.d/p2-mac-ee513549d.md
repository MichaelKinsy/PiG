### Added

- A native macOS app for p2 (apps/p2-mac, Pi's spike): a menu bar item that finds, runs, adopts or stops the local p2 server (`p2 server` from a checkout's build), and windows that show p2's web UI signed in as the local owner (the owner-key challenge of `/owner/local/challenge` and `/owner/local/claim`, the cookie put into the window's own store), with links, downloads, file panels, dialogs and the microphone handled natively. It is Swift (AppKit, WKWebView, macOS 14); the dev supervisor is absent in PiG (D473). <!-- feat: p2-mac -->
