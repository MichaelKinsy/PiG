### Fixed

- In RPC mode, a termination signal that arrives while the mode starts or tears down no longer skips the extensions' `session_shutdown`: the shutdown the signal started is now run by the mode itself when no signal hook was left to run it. A signal that was ignored during a running shutdown, followed by a stdout write failure that ends the mode, now leaves its `exit.log` line ("received SIGTERM during shutdown, which the mode's end cut off (exit 143)") and always exits 143 (D234). <!-- fix: 05102adc73 -->
