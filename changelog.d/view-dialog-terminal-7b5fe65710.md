### Added

- In the terminal, a view an extension mounts in the `dialog` slot is drawn in a titled frame centred over the screen, eight tenths of the terminal's columns and rows, with the keyboard: its list, its input and the keys it binds answer, and the panels and the editor under it keep their state. Only the extension closes a dialog. Several dialogs are stacked, the last shown on top. A frame is on the screen only while a dialog has the keyboard, so it never covers what you type: Escape returns the keys to the editor and folds the dialogs into one row above it (`<title>: F6 to enter`), F6 opens them again, and a dialog shown while you type in the editor waits on that row. The terminal states a dialog's size to extensions as the claims `size.columns` and `size.rows` of the slot.
