### Added

- In the terminal, a view an extension mounts in the `dialog` slot is drawn in a titled frame centred over the screen, eight tenths of the terminal's columns and rows, with the keyboard: its list, its input and the keys it binds answer, and the panels and the editor under it keep their state. Only the extension closes a dialog. Escape returns the keys to the editor while the dialog stays, and F6 moves between the editor and the dialog. Several dialogs are stacked, the last shown on top. A dialog shown while you type in the editor is drawn without the keyboard, so nothing you type is lost. The terminal states a dialog's size to extensions as the claims `size.columns` and `size.rows` of the slot.
