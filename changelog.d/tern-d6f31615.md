### Changed

- An interactive `pig` session starts with less memory: the 191 syntax grammars are no longer all decoded and registered at start. Each grammar outside the eager set is decoded the first time code in that language is highlighted, and automatic language detection decodes the rest the first time it runs; highlighted output is the same for every sample of the corpus (checked against the full eager load, including automatic detection over all 650 samples). The grammar load at start allocates 385 times and 2.3 MB instead of 1,135 times and 7.8 MB, and the first frame allocates 5.5 MB instead of 11.1 MB. On linux/amd64 with a fresh home, the median resident (and proportional) set after ten idle seconds is 46.5 MB (46.2-46.7, N=16) against 50.1 MB (50.0-50.5, N=16) before, and the median time to the first full frame is 24.6 ms (20.4-30.1, N=60) against 24.9 ms (21.2-33.5, N=60). The first highlight of a language outside the eager set decodes once (576 allocations, 3.1 MB) and the first automatic detection decodes the rest (1,857 allocations, 6.5 MB), both off the start-up path. <!-- fix: d6f31615 -->
