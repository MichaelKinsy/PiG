### Fixed

- A TypeScript extension that sends the bytes of an image in the `images` list of a plugin view (`{ ref, mimeType, data }`, with an `image` node that names the `ref`) now compiles: `PiGWireView` has the optional `images` member, `PiGViewImage` types its records and `PiGViewImageNode` types the node. The host accepted this view, as the `ui-views` page says, but the types rejected the object literal as one with an unknown member, so a Node author had to cast it. The plugin view API is unreleased and no release has the type. The type test is `extensions/sdk-ts/typecheck.ts`, which compiles a view with `images` and four wrong shapes that must fail (`make test-sdk-ts`). <!-- cause: PiGWireView declared only root, focus and theme, so the optional images list that the host reads from a view was not a known member, and no type test compiled a view with images --> <!-- fix: f633b88012 -->
