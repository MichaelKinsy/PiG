### Fixed

- For a provider built with `CreateProvider` (an SDK or natively registered provider, or a direct user of package ai) that fetches a large model catalog, every model lookup re-merged the provider's baseline and fetched catalogs on every read, slowing model selection and request setup for that provider; built-in providers were not affected; the catalog is now merged once when published (stored restore or network refresh) and cached, with public getters returning an owned copy and internal lookups reading the cached snapshot directly.
