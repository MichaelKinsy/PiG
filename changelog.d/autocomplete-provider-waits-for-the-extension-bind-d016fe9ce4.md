### Fixed

- Text typed before the extensions are bound (for example while an extension's `session_start` handler is still running) no longer opens the slash-command or `@` file menu, and Tab no longer completes a path there; the editor gets its completion provider when the bind ends, as in Pi. An editor an extension installs from `session_start` is installed with no provider and gets the provider when the bind ends or, if the host had already built it, when the host installs the editor, as Pi's `setCustomEditorComponent` does.
