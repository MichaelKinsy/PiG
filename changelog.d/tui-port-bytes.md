- Markdown now nests a `**strong**` run inside `*emphasis*` as Pi does, renders a line underlined with `===` or `---` as a heading, and leaves a blank row between a paragraph and a blockquote, heading, rule or math block that directly follows it.
- SettingsList draws Pi's bytes: its scroll indicator, description and hint rows are no longer padded to the width, and a row or hint that does not fit ends in `...` as pi-tui's truncateToWidth ends it.
- A `!` command block draws Pi's bytes: two consecutive blocks are separated by one blank row instead of two, the running hint names the `tui.select.cancel` keys (`escape/ctrl+c to cancel`) as Pi's does, and its rows are padded to the width with Pi's SGR closes. A quoted line followed by a lazy `===` stays quoted text, as in Pi, instead of becoming a heading.
