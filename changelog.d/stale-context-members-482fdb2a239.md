### Fixed

- A context an extension keeps past a Session replacement or reload now fails the theme, the terminal size, `setWidget`, the tool update and the SDK-extra `getSettings` with Pi's stale message, as it already did `cwd`, `mode`, `hasUI` and `model`. Before, these members kept working on the old context in the Go, Rust, Python and Lisp extension SDKs and a widget or tool update sent from it reached the new Session's host.
