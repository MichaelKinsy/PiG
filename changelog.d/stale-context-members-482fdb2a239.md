### Fixed

- A context an extension keeps past a Session replacement or reload now fails the theme, the terminal size, `setWidget`, the tool update and the SDK-extra `getSettings` with Pi's stale message, as it already did `cwd`, `mode`, `hasUI` and `model`. Before, these members kept working on the old context in the Go, Rust, Python and Lisp extension SDKs and a widget or tool update sent from it reached the new Session's host. In Go and Rust the theme and the size panic (`UITheme`, `Width`, `Height`; `theme`, `width`, `height`) and the calls return the error; Python raises `RuntimeError` or `HostCallError`; Lisp signals. `notify`, `setStatus`, `setActiveTools`, `abort` and the run signal in Go and Rust still answer on a kept context. <!-- fix: 482fdb2a239, 5f10e4f9cc2, 3fd07e39eb5, 481d6ff7f7c -->
