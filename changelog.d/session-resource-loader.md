### Added

- `coding.SessionOptions.ResourceLoader` and `coding.SessionStartOptions.ResourceLoader` supply the skills, prompt templates, context files and system prompt text a Session expands, reports and builds its default system prompt from, as `createAgentSession({ resourceLoader })` does in Pi. The Session reads the loader on every use and `Session.ResourceLoader()` returns it. When none is supplied, the Session uses a `coding.DefaultResourceLoader` over the Services' cwd, agent directory and settings, which reloads the Services' settings (dropping transient `ApplyOverrides`, as `createAgentSession` does) and discovers resources at construction. It resolves settings-configured paths and override patterns, `~/.agents/skills`, ancestor `.agents/skills`, configured Packages (installing a missing npm or git Package unless `PI_OFFLINE` is set) and `SYSTEM.md`, `APPEND_SYSTEM.md` and `AGENTS.md` files, records each resource's `sourceInfo` from its metadata (a Package keeps the path it shares with a settings entry and ranks after settings and auto-discovered resources), resolves Packages against the loader's own cwd and agent directory, and skips project resources while the project is untrusted. `coding.DefaultResourceLoaderOptions` accepts `AdditionalSkillPaths`, `AdditionalPromptTemplatePaths`, `NoSkills`, `NoPromptTemplates`, `NoContextFiles`, `SystemPrompt`, `AppendSystemPrompt` and the `*Override` callbacks. It does not load extensions or themes. `coding.NoResources` binds none and leaves the system prompt to the caller. `Session.SetPromptResources` replaces the loader's skills and prompt templates with the collections it is given.
