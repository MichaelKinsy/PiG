### Changed

- `pig` starts with about 500 fewer allocations and 88 KB fewer bytes (Linux, a warm first prompt with a `models.json`): the JSON Schema validator behind `Value.Check` no longer builds its draft tables, format map and message printer when the process starts, the empty cell manifest of a stock `pig` is no longer decoded through reflection, and the provider order of `models.json` is read once for the three startup callers that ask for it.
