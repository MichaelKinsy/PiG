### Changed

- An extension that subscribes to `context`, `turn_end` or `agent_end` costs less in a long session, in every mode and every SDK, with the same events and the same bytes on the wire: the host encoded every message of the conversation again for each model request's `context` event and now encodes only the messages that are new since the request before (a 150-message conversation: 7.4 ms and 1,648 allocations became 0.16 ms and 5), the encoder's compaction of a message's JSON crosses string text eight bytes at a time (200 to 970 MB/s), and a fused extension decodes the events the host just encoded without a second validity pass (-27% of the decode). A Bolt `-p` run of 50 tool turns with a plan-mode-style subscriber: a fused Go extension takes 40% less time (6.2 s to 3.7 s), packed and isolated Go extensions 25% less (7.5 s to 5.6 s), a Python subscriber 27% and a Node subscriber 17% less; the cost still grows with the length of the session. <!-- fix: c8d42f6c4 -->
