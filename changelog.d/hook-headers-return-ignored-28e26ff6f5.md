### Changed

- A map returned from a `before_provider_headers` handler is now ignored, as in Pi, in the Go, Python, Rust and Lisp extension SDKs, and for a handler an embedding program puts on `extension.Extension.Handlers["before_provider_headers"]` (the typed `extension.API.OnBeforeProviderHeaders` handler has no result to return). The headers a request carries are the ones the handlers leave on `event.headers`: edit `event.headers` in place instead of returning a map, and set a header to `null` to delete it from the request. A returned map replaced the headers in those SDKs from v0.2.0 to v0.7.0, so an extension that returned headers from this handler loses them until it edits `event.headers`; the Node SDK already ignored the return. A `before_provider_request` handler is unchanged: a payload it returns still replaces the request's payload. <!-- fix: 28e26ff6f5d393238e8f80bd41a4f80bcfffeb0e -->
