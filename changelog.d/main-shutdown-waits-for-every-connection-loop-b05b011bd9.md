### Fixed

- An extension process that dies while pig is quitting no longer produces a crash notice after the quit has returned, and `Host.Shutdown` now waits for the whole of every extension connection's read loop. A quit that coincided with a crash used to return while the loop was still reporting it, so the notice reached a session that was already gone, and a connection that no extension held as its current one (a second connection of an extension, one a reload replaced) was neither closed nor waited for at all. Shutdown now stops crash and disable notices first, closes every connection the Host reads, and waits for every loop for at most the bound of a process's stop; a loop that does not end in that time is named on stderr, as a process that does not end is.
