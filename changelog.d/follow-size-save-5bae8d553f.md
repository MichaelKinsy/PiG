### Changed

- A program that embeds PiG is smaller again (`examples/headless` on linux/amd64: 37.13 MB to 36.95 MB with a plain build, 30.59 MB to 30.50 MB with the strip tags). The model catalog's maps (headers, thinking levels, prompt cache) are built from pairs the linker lays out instead of a store for each model, brace expansion has one implementation (the memory-bounded one, which `internal/minimatch` now uses for every caller), the key, theme and keybinding tables that were built by code are data, and the Codex zstd encoder and the Mermaid Markdown parser are built on first use without being referenced by package initialization.
