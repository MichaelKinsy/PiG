### Changed

- A program that embeds PiG is smaller again (`examples/headless` on linux/amd64: 37.13 MB to 36.89 MB with a plain build, 30.59 MB to 30.44 MB with the strip tags). The model catalog's maps (headers, thinking levels, prompt cache) are built from pairs the linker lays out instead of a store for each model, brace expansion has one implementation (the memory-bounded one, which `internal/minimatch` now uses for every caller), the key, theme and keybinding tables that were built by code are data, and the Codex zstd encoder and the Mermaid Markdown parser are built on first use without being referenced by package initialization. Lower- and upper-casing in `tui`, `internal/codingagent` and `internal/nodespawn` use `internal/jsstring` (JavaScript's `toLowerCase` and `toUpperCase`) instead of `golang.org/x/text/cases`, which is no longer linked; the two agree on every code point and on the Final_Sigma contexts of ordinary text, and `jsstring` is the one that matches JavaScript where they differ: `cases` stops looking for a following letter after 30 case-ignorable characters, so `"ΑΣ"` plus 31 combining marks plus `"Β"` lowers to a final `ς` there and to `σ` in `jsstring` and Node; an ill-formed UTF-8 byte becomes U+FFFD in `jsstring` and passes through `cases`; a lone surrogate is kept by `jsstring` (see Fixed), as in JavaScript.
