### Changed

- A program that embeds PiG is smaller again (`examples/headless` on linux/amd64: 37.13 MB to 36.89 MB with a plain build, 30.59 MB to 30.44 MB with the strip tags). The model catalog's maps (headers, thinking levels, prompt cache) are built from pairs the linker lays out instead of a store for each model, brace expansion has one implementation (the memory-bounded one, which `internal/minimatch` now uses for every caller), the key, theme and keybinding tables that were built by code are data, and the Codex zstd encoder and the Mermaid Markdown parser are built on first use without being referenced by package initialization. Lower- and upper-casing in `tui`, `internal/codingagent` and `internal/nodespawn` use `internal/jsstring` (JavaScript's `toLowerCase` and `toUpperCase`) instead of `golang.org/x/text/cases`, which is no longer linked; the two agree on every code point and on the Final_Sigma contexts tested, and differ only on invalid UTF-8, which `jsstring` turns into U+FFFD as JavaScript does and `cases` passed through.
