### Fixed

- Startup now records the changelog version, and each extension package's version, before the UI and the extensions start, as Pi's `init()` does: a `session_start` handler that reads `settings.json` finds `lastChangelogVersion`. A resumed session that holds no message now records it and shows "What's New" like a new session, because Pi skips the changelog only for a session with messages. <!-- fix: dd09fd446a -->
- Extension commands now run one after the other where Pi awaits each prompt: among the positional startup messages, among the prompts you type while a command runs, and among the messages queued during compaction. The prompt after a command waits for its handler to return, and a queued prompt joins a run an earlier command started with its queued mode. <!-- fix: da65d9a454 -->
- Ctrl+C clears the draft (a second one exits) and Ctrl+D on an empty editor exits while startup is still finishing, for example during the first `fd` and `rg` download, as in Pi; the other application keys stay inactive until startup is done. <!-- fix: da65d9a454 -->
