### Fixed

- Resuming a session (`pig -c`, `--resume`, `--session`, and the SDK's `CreateAgentSessionFromServices`) whose saved model is gone no longer picks a model that your account does not list. The fallback chose from every model of a provider that had credentials, so an account that lists only some models (GitHub Copilot's list of models for your plan), or a provider whose own filter hides a model, was given a model it cannot use, where Pi gives it only a listed model, or none when none is listed and shows "No models available". The fallback now reads the same models `/model` offers. It was present in v0.7.0 and, in the startup path, in v0.3.0. <!-- fix: 60285d7fbd --> <!-- cause: both fallback selectors listed available models as the composed catalog filtered by provider auth, not the published availability snapshot, which applies each provider's per-credential model filter -->
