### Added
- `PIG_TUI_SCREEN_WRITER=1` (off unless set) makes fullscreen mode send the terminal only the cells a frame changes: a row whose text changes is written from its first changed cell, a frame that changes nothing is not written, and rows written in part are written whole once output has been quiet for 250 ms. The screen is the same as with Pi's bytes (checked cell by cell in alacritty_terminal, pyte, xterm.js, wezterm-term, libvterm and tmux, and on a pseudo-terminal through exit, suspend, resize, a slow terminal and Kitty image rows); the bytes differ, so a raw capture of the output (`script`, `tmux pipe-pane`) shows other bytes with the same text. `PIG_TUI_SCREEN_WRITER_LOG=path` records every write as it came and as it was sent (D624).
