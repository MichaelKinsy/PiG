- Keep OAuth credentials as Pi's complete token object. An `auth.json` entry with a fractional, absent or non-number `expires` no longer makes the whole credential store unreadable, and expiry decisions follow Pi's JavaScript comparisons. Extension refresh and API-key callbacks receive the stored credential, including `type: "oauth"` and provider-owned keys, and their results keep every key and the exact expiry in the Go, Rust, Python and Node SDKs.
- Builtin Anthropic, OpenAI Codex, Kimi, Radius, xAI and GitHub Copilot logins compute expiry with Pi's arithmetic, so a fractional or string `expires_in` is accepted and not truncated. Interactive and CLI logins now store the complete credential, including OpenAI Codex `accountId`.
