### Added

- chord: `LinksOptions.Opened` of `chord/nextnode/http` gets a third parameter, `closeLink`, that terminates that link at once, as a revocation does: no close handshake (the peer sees close code 1006), the link's other links stay open, a later call or a call after the link is gone does nothing, and any goroutine may call it; an app uses it to close the links of a credential it revoked. The function `Opened` returns runs once when the link closes, also when the hook ended the link before it returned (Pi 5f89cc0a7df6).
- chord: `contracts.MemberNamesOf(contract, variant)` returns the names of the state members, methods and event members of one variant of a contract's current version in the order declared (`MemberNameLists`; a local contract's variant is `contracts.LocalVariant`, and its keyed and queries members are not listed), for a helper that fills an implementation from another object's members. An unknown variant is the error `<contract>: no variant "<variant>"`. The vendored TypeScript chord of the page and plugin clients carries Pi's `memberNames` and the exported types `Method`, `LiteralsSchema` and `HostKeyed` (Pi 5f89cc0a7df6).
