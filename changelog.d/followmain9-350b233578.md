### Changed

- durable/codemode: code mode namespaces come from extensions, not name prefixes (Pi 5e24c6b1f). An extension declares one with `durable.Extension.Namespace` (`durable.ToolNamespace{Name, Description, Instructions}`) and it groups the tools the extension brings; a tool several extensions name belongs to the first one's. `codemode.Namespace`, its `Prefix`, `codemode.ToolOptions.Namespaces` and the unexported `namespaceOf` are removed with no replacement for prefixes: declare the namespace on the extension that brings the tools (for example one extension per MCP server) and use the plain tool names. `Section` takes the selected extensions instead of namespaces (`Section(tools, extensions, budget)`) and `codemode.NamespacesOf(extensions)` maps tool names to their namespaces. The `codemode` prompt section now lists the ungrouped tools first, then every namespace a selected extension declares, also one without tools yet, as `## <name>` and its one-line description with no tool counts (`(some tools not listed)` and `(tools not listed)` are gone; a single `Some tools are not listed: find them with searchTools().` line follows the heading line), so the prompt does not change when an extension's deferred tools appear. `Instructions` are returned only by `describeNamespace()`, and `searchTools()` searches the name, description and instructions. The start data of a code mode call lists a declared namespace without tools too, and always carries its description. The coding agent's own code mode and the extension SDKs are not changed.
