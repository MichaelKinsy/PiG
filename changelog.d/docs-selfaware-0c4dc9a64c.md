### Changed

- The docs bundle has a new page, `piglet-strip.md`, that explains how `tools` limits a Piglet, what the `strip` lists remove, and how to inspect the active Piglet. The README starts with four PiG-specific task rows and a hint to search `divergences.md` with `grep -n -i`. The README now puts the install and bundle details after the task table.
- The bundle pages `tui.md`, `sdk.md`, `themes.md`, and `custom-provider.md` link to bundle pages as `<page>.md`, and a drift test rejects root-absolute links in the bundle.
- The Additive features table in `divergences.md` is generated from `docs/additive-features.md` (`make additive-list`, part of `make generate`) and lists all additive records, each with a one-sentence `Summary:` line from the ledger. `knowledge-graph.md` has rows for the slot, strip list, and overlay Piglet, and it no longer names paths that exist only in a source checkout.
- The docs bundle has a new page, `extend-pig.md`, that ranks the ways to change PiG (settings, skills, extensions, Packages, Piglets, Binaries, source) with where files go and how to verify each one. The README leads with it. `additive-features.md` is a new generated page that lists the additive records written for authors, chosen by an `Audience:` line in `docs/additive-features.md`.
- The `skills.md` page names the real skill paths (`~/.pig/agent/skills/` and `~/.agents/skills/`), `themes.md` has the theme file format and the 51 required color roles, and `extensions.md` states which files load and that `--lang lisp` exists. `README.md`, `settings.md`, `extensions.md`, `skills.md`, and `piglet-strip.md` start with a short "Differs from Pi" box.
