### Changed

- Durable storage on SQLite opens its connection in SQLite's multi-thread mode (`SQLITE_OPEN_NOMUTEX`) instead of the serialized mode modernc.org/sqlite hard-codes, so SQLite no longer takes its per-connection mutex on every call. The connection was already used by one goroutine at a time (the serial operation queue holds every operation, `Close` included); a test now enforces that on the real driver connection. modernc.org/sqlite's driver layer is vendored in `internal/third_party/sqlite` with a `_threading_mode` DSN parameter until the same parameter is available upstream. On the storage benchmark's SQLite rows (n=12 interleaved runs, same host, pinned) the geometric mean is 8.3% faster: the document replay and historical reads 11 to 27% (p<=0.024), no row slower, allocations and bytes unchanged, commits unchanged.
