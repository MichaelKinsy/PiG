### Changed

- `examples/ui-view-web/bridge.mjs` no longer prints the page's token. Its first line is now `ui-view-web: http://127.0.0.1:<port>/ (open: <dir>/open.html)`. Open that file (`open <path>` on macOS, `xdg-open <path>` on Linux, `Start-Process <path>` in PowerShell): it sends your browser to the address. The bridge makes the file, and `address` beside it, in a private temporary directory (mode 0700, files 0600) and removes them when it ends. Do not give the content of `address` to a command as an argument: other users of a Linux machine can read process arguments. `--print-token`, or `UI_VIEW_WEB_PRINT_TOKEN=1`, prints the old line, `ui-view-web: http://127.0.0.1:<port>/?token=<token>`. The page now removes the token from the address bar after it loads and keeps it for that tab, the bridge compares the token in constant time and sends `Referrer-Policy: no-referrer` and `Cache-Control: no-store`, and it also ends cleanly on SIGHUP.
