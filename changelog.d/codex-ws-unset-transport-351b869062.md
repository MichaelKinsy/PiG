### Fixed

- A Codex WebSocket session whose requests name no transport (a caller of the `ai` package with `StreamOptions.Transport` unset, or a pi-ai helper that passes none) now sends the full context on its later requests, as Pi's do, instead of the delta of a cached context (one new item and a `previous_response_id`). The transports `auto` and `websocket-cached` still send the delta and `websocket` still sends the full context. PiG's `Agent` and `Session` name `auto` when no transport is set, as Pi's do, so the requests of the CLI are unchanged, and an extension's model calls through the host no longer add the settings' transport, as in Pi.
