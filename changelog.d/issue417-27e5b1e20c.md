### Fixed

- `pig piglet remove <name> --source` now deletes the prompt file `pig piglet add` copied for that Piglet, so an edited Piglet of the same name adds again instead of failing with `destination .../piglets/prompt.md already exists with different content`. Add records each copied file and its SHA-256 digest in `<name>.files.json` beside the registered YAML. Remove keeps, and reports, a copied file that another registered Piglet lists or references, or whose content changed after it was copied; it never deletes a file it has no record of. A leftover record whose YAML was deleted by hand lets `add` of the same name replace its unchanged files, and an add that still conflicts names the Piglet that owns the file or says that no registered Piglet copied it. A prompt copied by 0.7.0 or earlier has no record: delete that file yourself or use another relative prompt path. Replacing a source Piglet is `pig piglet remove <name> --source` and then `pig piglet add` (#417, reported by @Cade-Peterson). <!-- fix: 27e5b1e20c -->
