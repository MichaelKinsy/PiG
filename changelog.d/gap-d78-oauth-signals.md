- Node extension OAuth callbacks now receive Pi's AbortSignals: `refreshToken(credentials, signal)` gets its caller's signal, which a cancelled host request aborts, composed with Pi's 15 second timeout only when a stored credential is refreshed during auth resolution (a model refresh passes the caller's signal alone), and `login` callbacks carry the interaction `signal`. A signal an extension retains after the callback returns stays live and still follows its caller's later abort.
