### Added

- Extension SDKs (Go, Python, Rust, and Node through its own components): the component kit draws pi-tui's and pi-coding-agent's own components as host-rendered view kinds, byte for byte as Pi renders them (Pi-rendered goldens at widths 30, 72 and 120, held in every SDK's conformance cell): `BranchSummary`, `CompactionSummary`, `SkillInvocation` and `CustomMessage` (coding-agent's message components; a click toggles them as in Pi), `CancellableLoader` and `BorderedLoader` (the focused cancel key aborts and reaches the extension as an `abort` view event), `Input` and `Editor` (the host owns the text and the cursor and runs the component's own key and mouse handling once the view's focus names it; `submit`, `escape` and `change` view events carry the value and the cursor), `ScrollView` and `MouseRegion` (the handler crosses as a description and each event it ran for reaches the extension as a `mouse` view event), and `Autocomplete`, the `CombinedAutocompleteProvider` of an editor. The `ui.view.event` notification gains `submit`, `escape`, `abort` and `mouse` events and a `cursor` on change events.
- Extension SDKs: an `Editor` in a view shows `max(5, floor(rows * 0.3))` lines of the terminal's real height, as Pi's editor does; a view surface reaches the host's terminal height.
- Extension SDKs (Rust, Python): the `EditorBase` the delegated editor component gets is the ledger's cell for Pi's `Editor` and `CustomEditor` queries and setters; `Theme.sourceInfo` is reached by the theme fixtures of every SDK.
