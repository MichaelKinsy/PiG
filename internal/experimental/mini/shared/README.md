# Mini shared transport

This opt-in internal library ports Pi's `experimental/mini/shared` contracts. It does not add a command or contact a remote service.

`JsonConnection` owns a readable/writable pair. `SocketTransport` listens and connects over a local Unix socket. `ChildConnection` takes an already spawned child's stdin, stdout, and kill callback. The process owner still starts and waits for that child. `ParentConnection` uses the child's standard input/output and leaves stdout owned by the process.

Register close handlers before the first message handler. The first `OnMessage` starts delivery. Message handlers execute in registration order on one reader goroutine and must return promptly. `Send` serializes and queues a complete frame without waiting for the remote reader. Like Pi's writable stream, the output queue has no application-level cap; the owner must close an unresponsive connection. `Close` interrupts IO and notifies close handlers once. Each explicit `Close` invokes the supplied cleanup callback, including repeated calls, as Pi does. `Wait` joins the IO pumps; call it from the owner, not a message or close callback.

Framing splits only on LF. Empty lines are ignored. CRLF works because CR is JSON whitespace. An unterminated final line is discarded, unlike the separate published RPC mode's JSONL reader. Malformed JSON terminates this connection and is available through `Err`; this is Go's error boundary for Pi's uncaught parser exception. The serializer preserves literal HTML characters and U+2028/U+2029. A literal backslash followed by `u2028` is not converted into a separator.

The service API structs contain function fields. Context arguments and error returns represent process-local cancellation and Promise rejection; they are not wire arguments. Service tokens attach those API shapes and event types to the exact upstream service names. `SessionSnapshot.Lane`, `LaneEvent.Event`, and auth notices carry lossless `json.RawMessage` because this transport routes harness/auth-owned data without interpreting it. The owner decodes the payload into its domain types. No replacement harness types or default snapshots are fabricated here.

## RPC peer

`CreatePeer(connection, PeerOptions{})` creates a bidirectional peer. `Provide(peer, Worker, implementation)` registers a typed function-field API. `Use(peer, Worker, CallOptions{})` returns the same API shape with remote functions. These two operations are package functions because Go does not support generic methods. `peer.Provide` also accepts a `Service` map of context-aware handlers. `peer.Use` provides an untyped `Remote.Call` for routers and dynamically named services.

`Call` and `CallWith` block until one result or error arrives. A context cancelled before sending consumes an ID but emits no frame. Cancellation during a call sends `cancel` and rejects locally with `Call cancelled`. A configured `TimeoutMs` sends the same cancellation frame and includes the method and timeout in the error. The receiving handler gets a context whose cause is `Cancelled by caller`. Closing a connection rejects all pending calls and cancels all in-flight handlers with `Connection closed`. Late results and unknown response IDs are ignored. As in Pi, sends on an already closed connection are no-ops: a call begun after close still waits for its own context cancellation or timeout. Owners must bound such calls or avoid starting them after shutdown.

Handlers enter in frame order. Pi invokes an async handler synchronously through its first `await`; the Go reader likewise waits for a handler's synchronous prefix to finish. A handler must call `Yield(ctx)` immediately before a non-RPC blocking wait. `Call`, `CallWith`, and typed remote calls yield automatically after sending when passed the handler context. Preserve that context (or a derived context) through nested calls. Do not yield before the upstream synchronous effects have run. After yielding, the handler may complete concurrently with later calls, events, and replies. `Yield` releases frame delivery, not ownership: `Wait` still joins the entire handler. Calling `Yield` repeatedly or outside a handler is harmless.

The handler context is not a wire argument. A nil result becomes JSON null. Returned errors and recovered handler panics become error replies. The forward callback handles only absent services; a missing method on a local service is an error, not a forwarding request. Its Go context carries the same dispatch turn so forwarding can yield or make a nested call. It has no cancellation signal from this hop, matching Pi; its owner must arrange downstream lifetime management.

Service announcements retain insertion order and replace the remote inventory. Re-registering a service replaces its implementation without moving its name. `OnEvent` observes every event, including its optional destination. `On` filters by service name. Event callbacks run in registration order on the reader goroutine. A router republishes with `EmitRaw`, preserving the difference between an absent destination and an empty destination.

Liveness uses Pi's default silence interval and ping cadence. Any frame refreshes it. Set `DeadMs` to a pointer to zero to disable it. `Close` stops the watchdog, cancels handlers, and closes the connection. `Wait` joins the watchdog and handlers. Call it from the owner after closing, never from a handler. Context-cooperative handlers drain; a forward callback or handler that ignores shutdown still belongs to its owner and can keep `Wait` blocked. Protocol and asynchronous send failures are available through `Err`.

## Verification

Tests import the exact pinned upstream source through Node for the framing and handler-order oracles. The handler-order test sends adjacent calls and a service-replacement event through the production Go JSON reader and compares the invocation trace to Pi's `createPeer`. Dynamic, typed, and forwarding handlers must enter before the following event. The RPC integration test spawns the real Pi peer over child pipes and checks concurrent reverse calls, service errors, undefined-to-null results, forwarding, addressed events, cancellation causes, and late results. Other tests drive the Go implementation through in-memory duplex streams and an isolated filesystem socket. `go test -race ./internal/experimental/mini/shared` requires the repository's Node and Go toolchains but no package installation, model credentials, or external service.

`BenchmarkRpcRoundTrip` measures a typed worker call through two peers and the complete local JSON framing path. It reports allocations. Profile this benchmark before changing dispatch or serialization for performance; no speedup is claimed by this port.
