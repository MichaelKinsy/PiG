# Which CI jobs run when. automation/ci/ci-plan.sh turns this table into the job matrices of .github/workflows/ci.yml.
#
#   pr     runs on every event, in the light pull-request run and in the full run.
#   queue  runs only in the full run: merge_group, schedule, workflow_dispatch, and a pull_request while the
#          repository variable PIG_PR_CI_LIGHT is empty or the pull request asked for the full run (the ci:full label,
#          or ready for review).
#
# The full run is every row. The light pull-request run is the pr rows, and only when PIG_PR_CI_LIGHT is "queue" or "label".
# Neither mode lets a change land on a light run alone: "queue" leaves the full run to the merge queue, and "label" makes
# the pull request's CI result fail until the full run has run on its head. A row's check name is its job name plus
# its shard, in both runs. The optional fourth column names the make target a linux row runs in the light run when that
# is a subset of the full run's (default: ci-<shard>). .github/AGENTS.md renders this table.
#
