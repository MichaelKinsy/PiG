# Fail-closed path rules for the 12 PORT_MAP evidence shards (portmap-1..12) on pull_request runs.
#
# Every non-pull_request event (merge_group, schedule, workflow_dispatch, push) runs portmap-1..12
# unconditionally, and .github/workflows/nightly.yml also runs them on main. On a pull_request full
# run, automation/ci/classify-changes.sh classifies every changed file against this file:
#
#   - Any path matching a `trigger:` glob forces portmap=true (the 12 shards run).
#   - A path may skip portmap ONLY when it matches a `skip:` glob (known non-portmap surfaces).
#   - Fail closed: any unknown/unmatched path forces portmap=true!
#
# One shell glob per line (matched with case(1) semantics, so `*` crosses `/`), prefixed with
# `trigger:` or `skip:`. Blank lines and `#` comments are ignored. `trigger:` takes precedence over
# `skip:`.
