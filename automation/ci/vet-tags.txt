# Build-tag sets of the tree and the gate that compiles each. vet-tags.sh reads this file.
#   vet <tag>                  compiled by `make vet`: one go vet run of every package with all `vet` tags set together, so a file or test that builds only under the tag cannot break unseen.
#   other <tag> <gate>         not compiled by `make vet`: the named gate owns the compile (a toolchain or a switch go vet on this host does not have).
#   prefix <prefix> <gate>     every tag that starts with the prefix is compiled by the named gate.
# `vet-tags.sh check` fails on a tag that a //go:build line of a Go file names and this file does not list (a new tag needs a row here), and on a row whose tag no Go file names.
# Tags of the Go toolchain (GOOS, GOARCH, cgo, race, ignore, goexperiment.*, go1.N ...) need no row.

# Platforms, last: `make vet` runs go vet natively (the host, linux), then once for each `platform` row, then once more natively with all `vet` tags together.
#   native <os>                    the host's own pass.
#   platform <os> <arch> [VAR=v]   a `make vet` pass with GOOS and GOARCH (and VAR=v).
#   os-other <os> <gate>           not vetted by `make vet`; the named gate compiles it, or none does.
